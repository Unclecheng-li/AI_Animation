# Hero Transfer Flow

A green value packet travels the rail while balances debit and credit live. Function: **payout / transfer / fintech move**.

## Purpose

- Wallet, marketplace payout, and remittance heroes
- Packet travel synced with balance counters
- Deep forest money chrome

## Specs

- Packet x: 0 → 420 over 1.6s
- From $2400→$2280, To $860→$980
- Entry: `index.html`

## Usage

```bash
npx hyperframes preview
ui2v motion publish . --version 1.0.0
```

## Notes

Keep the packet amount equal to the debit/credit delta so the story stays honest.
