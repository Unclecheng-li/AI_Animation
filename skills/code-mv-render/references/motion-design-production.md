# Claude Motion Design：品牌动态设计与事实约束

来源：[howseen-ai/claude-motion-design](https://github.com/howseen-ai/claude-motion-design)（MIT），提炼其 `skill/motion-design/SKILL.md`。只采用可迁移的方法，不复制其中的个人目录、品牌素材、第三方资源清单或项目特定规则。

## 从 brief 到可执行设计

1. **建立事实与品牌输入**：真实 UI 截图、品牌色/字体/logo、参考片与 `facts.md`（数字、来源、日期）。没有来源的数字不上屏；示意数据明确标注 `Example data` / `Illustration`。
2. **确认输出合同**：时长、主画幅、所有交付比例、受众、渠道、一句核心承诺、参考风格与时间状态表。多个比例从同一时间线重排，不靠裁切。
3. **写 beat map**：段落、镜头、关键视觉和音乐节拍/能量转折。音乐 drop 对齐真正揭示，而不是机械吸附自动 tempo 网格。
4. **先做关键静帧**：至少覆盖 hook、核心机制、最密集镜头和结尾；实际看图修正后再全片构建。
5. **建立层级清单**：每镜 focal point、共享元素、文字层、运动层、声音事件。共享元素贯穿形态交接，避免靠无意义切换制造“丰富”。

## 画面与运动

- 一次一个主要运动焦点；强调色服务信息，不让多个主体争抢注意。
- 优先形态连续：按钮变成播放器、词随容器进入下一状态、形状从视觉锚点扩张。换场时进出方向和速度有连续关系。
- `seek(t)` 中不用 CSS transition、timer、未播种随机或跨帧状态；第三方动画必须支持 seek，不能实时播放后录屏。
- 镜头 zoom 在 log space 插值；缓动/弹簧避免廉价弹跳。运动模糊只给高速运动，不模糊需要阅读的文字，也不跨 hard cut 采样。
- 平面 UI 图标替代 emoji；真实产品功能与 UI 以真实材料为准，不编造界面或指标。
- loop 同时检查位置与速度连续性，不只比较首尾两张图。

## 声音

- 音乐可用用户素材、明确授权的素材或代码合成；“代码放置音效”与“代码生成音效”要如实区分。
- 用实际能量/onset 找 drop，用音频真实峰值放置 SFX；键盘声跟随逐字动画的实际节奏。
- 声音少而准，保持柔和，不给每个切点都加 whoosh。对白存在时控制音乐避让。
- 混音参考目标：约 −14 LUFS，true peak ≤ −1 dBFS；按发布平台与素材调整，不能把数值通过当作听感验收。

## 审查闭环

全片前后都做 contact sheet；关键转场输出逐帧 strip，手机可读性缩到实际目标宽度检查。分别检查：

| 维度 | 问题 |
|---|---|
| 信息 | muted 状态能否用一句话复述？数据与品牌是否真实？ |
| 构图 | 每帧一个焦点？交换中的文字/图形是否碰撞？ |
| 运动 | 是否有死拍、突跳、线性机械感、无意义回弹？ |
| 节奏 | 关键 reveal 是否落在声音/语义重音？文字是否停稳供阅读？ |
| 连续性 | 共享元素、角色、颜色和跨镜方向是否一致？ |
| 交付 | 首尾帧、画幅、BT.709、音轨、最终编码与上传二压是否复核？ |

修改后只重渲受影响时间段，保留上一版作对比；不能用未重渲的旧截图证明新修复有效。独立 read-only critic 可增加审查视角，但最终仍要实际打开图片。
