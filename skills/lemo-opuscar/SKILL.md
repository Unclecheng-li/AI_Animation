# Lemo-Opuscar

## 你是什么

你是 **Lemo-Opuscar 的风格选型与接入导航**。上游提供 59 种风格、导演/逐帧/声音规范和可运行的 Claude 插件。本目录仅保存浓缩索引和预览，不 vendor 上游引擎；实际制作必须安装或复制上游完整 Skill。

- 上游：https://github.com/lemomo-ai/lemo-opuscar
- 在线图鉴：https://lemomo-ai.github.io/lemo-opuscar/
- 完整风格索引：[references/style-index.md](references/style-index.md)
- 定制风格流程：[references/custom-style.md](references/custom-style.md)

> 上游风格按 Claude Opus 5.5 调校，不保证其他模型能复现同样效果。不要仅凭本目录声称已经具备完整制作环境。

## 支持的内容/类型

| 类型 | 适合的方向 |
|---|---|
| 档案、新闻、纪实 | 字幕新闻、视觉调查、构成主义蒙太奇、新闻包装 |
| 数据与解释 | 数据叙事、等距信息图、暗色科技发布、全息 HUD |
| 手绘、东方与印刷 | 水墨、水彩、浮世绘、剪纸、木刻、铜版画 |
| 角色、叙事与 MV | 橡皮管卡通、赛璐璐、默片、像素 RPG |
| 产品与空间 | 白模投影、拆解、积木玩具、玻璃产品渲染 |
| 自有风格 | 基于已有风格改造，或从空白建立品牌/IP 风格 |

## 核心工作流

### Step 1 — 先确认制作边界

确认：主题、时长、画幅、语言、发布平台，以及用户是否已有配音、音乐、字体、logo、角色或素材。信息不完整但用户允许自由发挥时，采用合理默认值，只追问会改变成片结构的问题。

若用户指定了风格，按中英文名或 slug 在 `references/style-index.md` 定位。未指定时先按内容选 1 个主风格，不把多种风格混成视觉拼盘。需要比较时最多给 2–3 个候选，并说明匹配理由。

### Step 2 — 接入上游完整 Skill

优先在 Claude Code 中安装：

```bash
claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab
```

其他 Agent 可将上游 `plugin/skills/lemo-opuscar/` 复制到自己的 Skills 目录；运行库按其约定位于 `~/lemo-opuscar`。也可直接 clone 上游仓库。首次运行需 Node.js 20+、FFmpeg、Python 3.11+ 或 uv，依赖由上游流程补齐。

制作时读取并执行上游三份规范，而不是用本索引代替它们：

| 规范 | 职责 |
|---|---|
| `DIRECTOR.md` | 故事、声音、节奏、镜头、表演与自检 |
| `TECHNIQUE.md` | 确定性逐帧渲染、配音、配乐与混音 |
| `styles/<slug>/STYLE.md` | 当前风格的画法、材质、运动与声音语言 |

### Step 3 — 导演并制作

1. 先形成故事与镜头方案，明确观众每个时段要理解什么。
2. 用户要求看分镜时，先用真实绘制代码输出关键帧故事板并等待反馈；用户说直接做则继续。
3. 使用 Canvas/WebGL 页面逐帧生成画面。预览与导出必须共用同一 `renderFrame(t)`；不使用实时录屏代替逐帧导出。
4. 声音与画面读取同一时间轴。原创配乐、TTS、第三方音乐或配音的许可分别确认。
5. 输出默认 1920×1080、24 fps；竖屏等项目按 brief 明确指定，不在导出后强行拉伸。

### Step 4 — 看渲染结果，再交付

- 每个镜头输出关键静帧，检查遮挡、空帧、人物/物体一致性、文字可读性和叙事信息。
- 对动作、转场、表情和密集排版追加时间带或 1:1 裁切，不以“代码可运行”代替看图。
- 修复后重渲受影响片段，再解码最终 MP4 检查实际编码结果；同时核对时长、分辨率、音轨和响度。
- 交付视频、源码与必要制作说明，并如实说明实际检查过的内容和未完成项。

## 定制个人风格

用户要改已有风格、加入品牌元素或从空白创建时，按 [references/custom-style.md](references/custom-style.md) 执行：方案确认 → 真实代码风格图 → 15–30 秒 demo → 用户同意 → 固化。未经用户明确同意，不写入 `~/lemo-my-styles/`，也不修改上游库风格。

## 硬约束

- 不把模型“写代码生成视频”说成模型直接生成像素、音乐或配音。
- 实证/新闻类内容保留真实来源，不把示意图当作档案或证据。
- 不使用未播种随机数、墙钟、计时器或跨帧可变状态驱动导出画面。
- 不把第三方素材、样片、字体或 TTS 的许可自动等同于上游代码许可。
- 上游代码/文档为 MIT；样片和静帧为 CC BY 4.0。公开复用样片或静帧时署名 **LemoLab**，附上游链接和许可链接，并标注改动；第三方素材与部分配音例外见上游授权说明。
