# 机制参考：播放器 · 镜头 · 音效（浓缩版）

底盘代码全部内置于 `assets/template.html`（cp 复制，勿通读），本文件是改写时的速查。

## 播放器底盘（[不动]区）

- **虚拟时钟**：`<head>` 第一个脚本劫持 `performance.now()`/rAF——点「启动播放」前时间恒 0，点击后 600ms 按钮淡出 → 1.4s 黑场淡出 → 2s 时 `__startPlayback()` 起跑。CSS 动画与 JS cue 共用此时钟，永不漂移；质检可快进任意毫秒。
- **舞台**：1920×1080 固定坐标，`transform:translate(-50%,-50%) scale(s)` 适配窗口；绝对定位像素布局，安全边距左右≥52/上下≥34。
- **HUD**：默认隐藏（`body.hud-off`），鼠标到视口底部 60px 唤出；进度条+时间码+暂停/重播；播完 `.done` 呼吸光晕。
- **时间轴**：`on(毫秒,回调)` 一次性 cue + `tws` 补间（`fly` 抛物线飞行 / `cnt` 数字滚动 / `after(ms,f)` 相对排程）；暂停时 `t0+=暂停时长` 且 `body.paused` 冻 CSS 动画（两者必须同步）；重播=`location.reload()`；cue 注释引用口播时间戳。
- **字幕条**：底部 96px 胶囊走廊（#cam 外，不随镜头），逐句 show/remove，间隔≥300ms，`<b>` 高亮主色。

## 镜头调度（#cam 层）

```js
#cam{transform-origin:0 0;transition:transform var(--cd,1.4s) cubic-bezier(.16,1,.3,1)}
camTo(tx,ty,s,dur)          // 自动挂 whoosh
camFocus(fx,fy,s,dur)       // 对准(fx,fy)推到 s 倍，自动收边不出画
```

缩放范围 1.0–1.35（推近常用 1.12–1.3）。字幕/角注/HUD/黑边放 #cam **外**。六种调度：

| 调度 | 用法 | 参数感 |
|---|---|---|
| 开场拉镜 | 几乎每页：CSS 初始=特写位，开演 300ms 后 `camTo(0,0,1,~2s)` | init scale 1.15–1.32 |
| 关键推近 | 数字揭晓/盖章/结论：`camFocus(x,y,1.15~1.25,.8~1.2)`，每页 2–4 次 | |
| 转场拉回 | 新面板入场前 `camTo(0,0,1,1~1.3)` | |
| 跟拍 | 主体逐站点亮：依次 camFocus 每站，0.8–1.0s/段 | 1.28 倍紧跟 |
| Ken Burns | 标题卡缓推：如 `camFocus(960,470,1.13,5)` | 5s 无感放大 |
| 冲击快推 | 爆发瞬间 0.45–0.6s 怼脸配 thud，随后 1.2s 拉回 | |

**慢放组合拳**（并发毫秒级过程时）：`.letter` 黑边条(74px)+`#dim` 暗角+慢放标签胶囊+毫秒计数器+推近，段落结束逐一退场。

## 音效（WebAudio 合成，零音频文件）

引擎在 template 第二节，六原语：`pop`(波·弹出)、`whoosh(dur,vol)`(呼·镜头/大位移)、`swipe`(唰·快切)、`type`(键击)、`ding`(叮·落定)、`thud`(咚·撞击/盖章)。

- cue 写在时间轴尾部 `/* ===== 音效 ===== */` 块，与视觉 cue 同帧（±50ms）；
- **Tn** 等距连击：`for(i<n)on(t+i*gap,()=>__sfx.type(v))`；**TnE** 缓出连击（先密后疏，末击=计数结束）：`u=i/(n-1); tt=t+span*(1-(1-u)**(1/3))`；
- 音量层级：主揭晓 0.9–1.2 / 日常 0.4–0.6 / 背景连击 0.28–0.4；一秒≤2–3 个音，换气留 ≥0.5s 静默；
- master 0.24 + lowpass 6500 已调好，勿改。
