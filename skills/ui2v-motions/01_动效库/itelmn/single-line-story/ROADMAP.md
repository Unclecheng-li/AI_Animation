# Roadmap

## v0.1 — launch library

- Eight native HyperFrames template families
- Generic CSV/JSON compilers and per-family data contracts
- Two or more visual variants per family
- Seek-safe shared runtimes
- Upbeat soundtrack, opening, finale, and close on every composition
- Portable Plotbeat AI skill
- Lazy-loaded rendered gallery previews
- Template manifests, schema, tests, and release audit

## After launch

- Choropleth and route-map variants
- Annotation tracks and event callouts
- Explicit missing-data strategies
- Theme tokens and brand import
- GitHub release automation
- More data grammars based on reusable user requests

## Template acceptance bar

Every template must have a documented data contract, generic sample data, seek-determinism tests, a final landing state, responsive copy safeguards at its target resolution, clean HyperFrames checks, sampled snapshots, and an approved Studio preview.

Feature requests should propose a reusable visual grammar and data shape rather than a one-off hard-coded dataset.
