# 动效框架 · 从《world.execute(me);》抽取的可迁移规范

> 来源：`world-execute-me-lyric-mv` v4 的 `docs/v4/PLAN.md`、`docs/v4/KIT.md`、`src/engine/transitions.js`，以及本库自建案例《CVE 编号破十万》。
> 本文件只写方法论与参数，不复制原片素材、歌词或角色图。

这套框架解决一个问题：**让每一帧都"有理由"，而不是把元素堆上去再补动画。**
它由五层组成：镜头模型 → 入场转场 → 镜头内运动 → 字体与遮罩 → 时间与后期。

---

## 1. 镜头模型：一个镜头是一个带时间的纯函数

上游的段落文件里，每个镜头是一个对象：

```js
{
  id: 'counter-arrive',
  at: B(12),                  // 切点，必须落在拍/半拍/小节线，不写裸数字
  lines: [0, 0],              // 这个镜头负责的歌词行（数据视频里换成字幕段）
  moment: '编号跨过 100000 的那一拍',   // 一句话，必填
  layout: 'interface:',       // interface: / PLATE: / CODE: / DATA:
  palette: 'on',              // 颜色状态，不是风格
  enter: { type: 'scan', dur: 0.46, align: 'end', dir: 0 },
  camera: (t) => ({ x: 0, y: 0, zoom: 1, rot: 0 }),
  render(ctx, t, f, u) { /* 只依赖 t 的绘制 */ },
}
```

三条硬规则：

1. **镜头有且只有一个"时刻"**。写不出 `moment` 的镜头就是多余的。
2. **切点在时间网格上**。音乐用 BPM 网格；口播/数据视频用字幕段时间 + 事件时间（见 §6）。
3. **`render` 是纯函数**。不读 `Date`、不存跨帧状态、不用 `Math.random()`；需要随机就用种子 PRNG。

镜头内部通常分三拍：

| 拍 | 时长 | 做什么 |
|---|---|---|
| 入场 | 0.25–0.8s | 主体到位（eased），附属元素 60–120ms 后跟进 |
| 展开 | 主体停留 | 数字滚动、条形增长、行逐条出现、镜头缓推 |
| 收束/交接 | 0.2–0.6s | 由事件结束（用户动作、界面事件、下一拍），不是"时间到了随便淡出" |

## 2. 入场转场：15 种，按语义选，不按好看选

`enter` 写在**新镜头**上，在相邻镜头的时间重叠区执行：

```js
enter: { type: 'glitch', dur: 0.4, align: 'start', color: 'err' }
```

- `align: 'end'`：重叠结束于切点（适合推近、擦除**落在拍上**）
- `align: 'start'`：重叠开始于切点（适合 glitch、shatter 这类**由拍触发**的）
- `align: 'center'`：跨切点
- 任何类型都可加 `flash / flashColor / flashDecay`，但整句只允许 ≤0.3 的一次闪

| type | 机制 | 参数 | 语义 / 用在哪 |
|---|---|---|---|
| `cut` | 硬切 | `flash?` | 默认；关键词砸下、数字落定 |
| `fade` | 溶解 | — | 消失、离线、结尾 |
| `glitch` | 块 + 撕裂行互换，**每个块只切换一次**，不来回抖 | `dur` | 错误、异常、数据不一致 |
| `scan` | 扫描线擦除，带热边 | `dir 0下/1上/2右/3左` | 打印、开机、数据写入 |
| `circle` | 从一点开光圈 | `x,y,inverse` | 聚焦某个对象 / 从对象拉开 |
| `diag` | 斜向板条擦除 | — | 话题快速切换 |
| `grid` | 16×9 单元格对角级联翻转 | — | 参数、表格、批量数据 |
| `zoom` | 穿过画面（8 次径向模糊采样，不是硬线） | `x,y,out` | 深入内核 / 拉远看全貌 |
| `shatter` | 三角碎片下落 | — | 破碎、结论被推翻 |
| `dissolve` | 像素块随机翻转 | `size` | 数据衰减、遗忘 |
| `winclose` | 画面像窗口/CRT 收成一条线 | `x,y` | 关闭、离开、断电 |
| `winpop` | 画面以 back-ease 弹出为窗口 | `x,y` | 记录页、弹窗、新进程 |
| `push` | 两画面整体推移 | `dir` | 两个状态/两章之间 |
| `slices` | 横向切片交错滑开 | `bands` | 撕裂、冲击 |
| `flashcut` | 切点藏在颜色 bloom 里 | `strength` | 大段落切换 |

**使用纪律**

- 同一个视频里，转场种类不超过 4–6 种；重复使用形成语法。
- 有脸/有人物的画面：只允许硬切、fade、错版、掉帧；不做撕裂、RGB split、形变。
- 数据类内容优先 `scan / grid / winpop / cut`，不要用 shatter 装饰。
- 转场不是遮丑工具：切点两边的构图要能对上（同位置、同轴线、同色温）。

### Canvas 2D 移植（本库已实现）

上游是 WebGL 片元着色器；本库把 15 种转场移植成零依赖 Canvas 2D：

```html
<script src="transitions2d.js"></script>
<script>
MVTransitions.paintTransition(ctx, {
  type:'scan', k:0.5, w:1920, h:1080, dir:0, edge:'#E2542C'
}, drawA, drawB);   // drawA / drawB 各画一层，k=0 全 A，k=1 全 B
</script>
```

- 文件：`templates/transitions2d.js`
- 逐个预览：`templates/transitions-demo.html`（15 段，每段 2.4s）
- 实现差异：`zoom` 用缩放 + 交叉淡化代替径向模糊；`glitch` 用横条位移代替块级 RGB 分离；`shatter` 用三角网格位移代替逐片着色。语义与节奏一致，性能更好。
- 只在镜头重叠的 0.3–0.6s 内调用；转场两侧各画一次到离屏 canvas，避免每帧重绘两遍场景。

## 3. 镜头内运动：六条语法

1. **缓动优先**：位移/缩放走 easeOut / easeInOut；只有机械计数器、扫描线、数字滚动用线性。
2. **错峰**：多个元素不同时到。主元素 0ms，附属元素 +60–120ms，第三层 +180–300ms。
3. **二次运动**：主体停住后，附属物再轻微过冲/回弹（数字落定后的 1.8% 脉冲、印章落下后的 0.1 回弹）。
4. **快速运动必须带模糊**：推镜、甩镜、翻页用径向/方向模糊；静止背景不参与重绘。
5. **禁止"只做透明度"**：淡入必须伴随位移、遮罩、印刷揭示、尺寸变化中的至少一种。
6. **闪入要整块**：图形"闪入"应在 1–2 帧内完整出现，前面不加白场；否则会像加载失败。

### 镜头运动（camera）

```js
camera: (t) => ({ x, y, zoom, rot })
```

- 全片只需 1–2 次真正的推镜；其余用画面内的层级位移制造深度。
- 推镜幅度 1.00→1.04 足够；超过 1.12 会暴露字体栅格化。
- 转场期间的相机运动要连续：新镜头第一帧的 zoom 应接近旧镜头最后一帧。

### 数据类镜头的"三拍"配方

| 配方 | 入场 | 展开 | 收束 |
|---|---|---|---|
| 计数器 | 数字从小一号推到位 | 数字滚动，末尾减速；落定瞬间颜色切到事件色 | 下划线扫开 / 角标时间出现 |
| 对账条 | 基线先画，条从 0 长出 | 数字同步计数；差额括号在第二条到位后出现 | 来源脚注淡入 |
| 记录页 | 窗口 winpop / 硬切 | 字段逐行下落 28px + 淡入，间隔 0.28–0.36s | 印章 scale 1.55→1 落章 |
| 时间线 | 轴线从左画出 | 节点依次点亮，颜色只给当前节点 | 当前节点卡片上浮，前一个降为灰 |
| 收束 | 黑场硬切 | 三行字按 1.2–1.5s 间隔逐行揭示 | 最后一行留 ≥1.2s 静止 |

## 4. 字体运动：字是主体，不是装饰

上游 `type.js` 提供的能力，可直接照搬思路：

| 能力 | 做法 | 用在哪 |
|---|---|---|
| `big` / `slam` | 大字以 1.08→1.00 砸下，0.18–0.25s，落定即停 | 关键词、结论 |
| `typed` | 逐字出现，节奏跟口播/歌词 | 界面输入、定义句 |
| `onPath` | 文字沿路径排布 | 圆环、曲线、时间轴 |
| `wall` | 整面字墙，作为纹理 | 编号背景、代码背景 |
| `sliced` | 文字切条错位 | 故障、撕裂 |
| `scramble` | 字符乱码收敛为真字 | 解码、数据加载 |
| `limp` | 字被切成 n 条竖带，向基线压扁、下坠 | 情绪崩塌、失效 |
| 遮罩字 | 用文字/形状当窗口看底图 | 版画、影像与字的结合 |

**中文注意**：中文没有词间空格，逐字出现要按"字"而不是"词"计时；标点不要单独占一拍。
关键词（数字、CVE 编号、结论词）用大字；解释性字幕永远在固定字幕带，不参与大字动画。

## 5. 印刷/版画类画面的运动

- **错版（misregistration）**：同一图形画两遍，副版偏移 10/18/28px，是"情绪强度"的刻度，不是随机抖动。
- **缺版**：抽掉一个墨版，留下虚线轮廓，表示"缺席/被删除"。
- **网点/纸纹**：静态底图预生成一次；每帧只叠一层 4%–6% 的 grain，避免闪烁。
- **遮罩揭示**：大字的入场用矩形/形状裁剪从左到右揭示，比淡入更像"印上去"。
- **印章**：scale 1.55→1.0 + 轻微旋转（-5°~-8°），落章后不再动。
- **曝光棘轮**：一个镜头内亮度只升不降；要降必须切镜头。整段只允许 3–4 次回落（关键词闪光、白场）。

## 6. 时间系统：把"拍"换成你的时间基准

### 音乐

```
beat 0 = 0.344s，130 BPM
1 beat = 0.4615s
bar n  = B(n) = beat 4n
半拍 = 0.2308s；三连音 = 0.1538s
```

### 口播 / 数据视频

没有 BPM 时，用同样的结构：

- **主网格** = 字幕段起点/终点（一句话一个镜头或两个镜头）。
- **次网格** = 句内关键词时间（数字落定、名词出现、转折词）。
- 所有"不在网格上"的时间集中到一个 `CUES` 表，一行一个，注明来源（实测/估算）。
- 镜头切点必须落在句子边界或关键词上；不要在一句话中间硬切。

### 时间特效（直接可复用）

| 特效 | 公式/做法 | 用途 |
|---|---|---|
| 掉帧 | `Math.floor(t * 12) / 12` | 模拟 12fps 胶片、故障 |
| 重放 | 在若干起点 `s` 处，把 `[s, s+len]` 这一段按 `t` 映射回放 | 同一动作重复、循环 |
| 插入镜头 | `withInserts(def, until, inserts)`：离开界面镜头去一张版画，再回到"本该到达的状态" | 关键词插入，不打断叙事 |
| 撕裂 | `tearAt(ctx, t, at, amount)`：撕裂图案持续 6 帧，不逐帧变化 | 冲击，不闪烁 |
| 余像 | 同一图形在 `t-0.05` 再画一遍，低透明度 | 运动拖尾 |
| 白场 | 全屏白 11–16 帧，再切回 | 章节重置（全片 ≤2 次） |

## 7. 后期光效：默认全关

上游 `ctx.fx` 的清单与默认值：

| 参数 | 作用 | 默认 |
|---|---|---|
| `glow` | 局部泛光（只对饱和色） | 低 |
| `bloomAll` / `bloomThreshold` | 米白与过曝橙也泛光 | 0 |
| `rays` / `raysAt` | 从一点向外的光线 | 0 |
| `streak` | 水平光条 | 0 |
| `zoomBlur` / `zoomAt` | 向一点拉伸的模糊 | 0 |
| `rgbSplit` | 色差 | 0 |
| `glitch` / `mosh` / `mosaic` | 故障/数据摩什/马赛克 | 0 |
| `scan` | 扫描线 | 0 |
| `invert` / `desat` / `bright` | 反相/去饱和/提亮 | 0 |

纪律：**光效只在事件上开，镜头结束必须回 0**；同一个镜头不要同时开三种以上。

## 8. 验收清单（逐条看帧）

1. 每个切点：切后第一帧构图是否成立？两帧之间有没有"空一帧"？
2. 每个关键词：落定帧是否是该句的视觉峰值？前后 0.5s 有没有竞争元素？
3. 每个事件：颜色变化是否只在事件发生的那一帧？之前有没有提前泄露？
4. 运动：是否至少有两层不同速度？是否只有透明度？
5. 数据：数字与字幕是否同步到最终值？计数过程中字幕是否说了最终值？
6. 时间：所有切点是否落在字幕/拍点网格上？
7. 安全：任意 1 秒内大面积亮度往返 ≤3 次；红色闪烁单独统计；快速图案至少保持 6 帧。
8. 收束：最后画面静止 ≥1.2s；不要用运动结束。

## 9. 迁移到"数据纪录片/口播视频"的映射表

| 原片概念 | 数据视频里的对应物 |
|---|---|
| 歌词行 | 口播句子 / 字幕段 |
| 关键词大字 | 数字、年份、CVE 编号、结论词 |

| 三墨版画 | 纸底定义页、概念图、印章页 |
| 角色色 = 状态 | 语义色：中性/里程碑/风险/缺失 |
| 节拍 | 句子边界 + 关键词时间 |
| 副歌四张版画 | 一组并列案例卡片（4–6 张） |
| EXECUTION 代码段 | 工具链/正则/命令章节 |
| 曝光棘轮 | 论证逐层加码，直到结论帧最亮 |
