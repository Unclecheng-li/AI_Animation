# Hero Film Countdown

A cinema leader counts 3 → 2 → 1 → 0 inside a framed gate with sprocket rails. Function: **standby / intro bumper** before a feature moment.

## Purpose

- Event opens and premiere heroes
- Classic film language without footage
- High-contrast black frame aesthetic

## Specs

- Number swaps at authored labels
- Red ring rotates through each beat
- Entry: `index.html`

## Usage

```bash
npx hyperframes preview
ui2v motion publish . --version 1.0.0
```

## Notes

Hold zero briefly with a fade — do not smash cut out of the last frame if this is used as a carousel opener.
