# Hero Checklist Pop

A concrete launch checklist checks off four shipping steps while a side card explains the function. This is task-completion UI motion.

## Purpose
- Onboarding and launch readiness heroes
- Functional checkbox choreography
- Light productivity aesthetic

## Specs
- Items enter then mark done via classList at timeline labels
- Side panel explains the interaction metaphor

## Usage
npx ui2v@latest install hero-checklist-pop and scrub each check beat.

## Notes
Seeking backward may leave classes applied; for heroes played forward this is acceptable presentation behavior.
