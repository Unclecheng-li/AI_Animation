## 文件夹 SVG 图标（手绘矢量，禁用位图）

模板自带基础款（黄色文件夹/此电脑显示器/回收站/地球浏览器）；特殊文件夹在基础款上加角标（Windows 加蓝色小窗、剪映加胶片格）。全部 66×52 viewBox 手绘，描边 1.5–2。

## 教学标记层（叠在还原界面上的"老师的手"）

- **问号徽章 `.q`**：30px 黄圆 + 黑问号，`scale(0)→1` 弹簧——"哪个能删?"式悬念，逐一 pop；
- **警告徽章 `.badge-warn`**：红边白底小胶囊（"磁盘空间不足"）；
- **容量爆红**：`.dbar i.red` + barPulse 亮度呼吸；
- **poof 删除动画**：`.fitem.poof` scale 1.12 rotate → 0（文件被删的"消失感"）；
- **红圈标记 / 警告花字 / 占比浮层**：按镜头手绘叠加，保持"轻盈的手"不遮界面。

## 动效参数

- Fluent 窗体缓动统一 `cubic-bezier(.16,1,.3,1)`；对话框/徽章弹簧 `cubic-bezier(.2,1.3,.4,1)` / `(.34,1.6,.64,1)`；
- 列表 stagger 95–110ms；右键菜单必须快（.16s）；通知 .6s 滑入；
- 镜头调度沿用 camTo/camFocus（推近幅度收敛，别把窗口推出画）。
