## 角色表情特写（吐槽担当）

视频演示最容易被记住的不是数据，是**情绪**。给系列安排一位常驻角色（动漫立绘表情包/Mascot），在合适节拍放大登场、吐槽一句——信息密度之外提供节奏呼吸和人格记忆点。

### 登场规范

```html
<div id="mascot">                                  <!-- 底部角落，宽 300–420px，部分出血 -->
  <div class="say">吐槽台词，<b>关键词</b>高亮</div>  <!-- 白色气泡，CSS 三角尾巴指向脸 -->
  <img src="表情包/12_粉颊捧笺_娇羞雀跃.png">
</div>
```

```css
#mascot{position:absolute;left:-10px;bottom:-8px;width:400px;opacity:0;transition:opacity .9s ease}
#mascot.show{opacity:1}                             /* 淡入淡出：9s 缓入，不是弹跳 */
#mascot img{width:100%;animation:bob 3.1s ease-in-out infinite alternate}   /* 常驻上下漂浮 */
#mascot .say{position:absolute;right:-160px;top:96px;width:230px;background:#fff;
  border-radius:16px;padding:13px 17px;font-size:24px;font-weight:900;
  opacity:0;transform:scale(.6);transition:all .45s cubic-bezier(.34,1.6,.64,1)}
#mascot.show .say{opacity:1;transform:scale(1);transition-delay:.45s}        /* 人先现，话后到 */
```

### 使用规则

- **尺寸要敢大**：400px 级别、压住画面一角、允许出血——这是"特写"，不是角标。半高的没人看。
- **情绪匹配节拍**：惊喜→雀跃款；翻车→茫然/扶额款；严肃结论→认真款；无语→忧郁款。项目开始时建一张"情绪→文件名"映射表，15 个情绪足够覆盖全片。
- **每页 1–2 次**，停留 4–8s 后淡出（`classList.remove('show')`），不常驻抢戏。
- 台词一句以内、口语化、带一个高亮关键词（`<b>` 用强调色）。吐槽 ≠ 解释，是反应：「充 50 到账 100…双倍？!」
- 登场配 `pop(0.6)`，音量轻。
- 没有立绘素材时：用纯 CSS/SVG 画一只圆脸吉祥物（两个状态：正常 + 惊讶），同样的位置与气泡规范。

## 字幕条（口播同步）

- 位置：底部 96px 一条走廊，胶囊形（999px 圆角）、深底白字、23–25px/900 字重。
- **逐句与口播对齐**：台词出现即 `show`，说完即 `remove('show')`，间隔 ≥300ms 防闪烁。一页 2–5 条。
- 关键词用 `<b>` 强调色（与本页主色一致），每条最多 1–2 处。
- cue 注释写口播时间戳：`on(5000,...)  // 5:06「系统一般会过一遍检查」`。
- 字幕条是"放映层"元素（#cam 外），不随镜头移动。

## 数字与状态 HUD（跨页连续性）

- 右上角状态胶囊（比分/累计分数/进度）与字幕层分离；跨页延续的数字**从上一页的终值起滚**（观众感知"故事在继续"）。
- 数字滚动用 `cnt()`（1.4s ease-out）配 TnE 连击键音；落定后容器 `.pump` 弹一下（scale 1.1 + 金色光晕）。
- 重大加分/扣分在 HUD 上方飘字（`+240 本片单洞最高分`，上浮 2.4s 消散）。

## 情绪节拍表（写 cue 前先填）

给每个镜头标 1–2 个"情绪锚点"：什么时候该惊讶、什么时候该笑、什么时候该严肃——角色登场、盖红章、慢放黑边、音效重音全部围绕锚点排布。一页里情绪锚点 ≥2 个，页面就不会"平"。
