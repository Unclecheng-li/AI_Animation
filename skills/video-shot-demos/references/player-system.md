# 播放器系统（黑场起手 · 虚拟时钟 · HUD · 时间轴）

所有页面共用同一套"底盘"。**底盘代码不做风格化定制**（按钮样式保持中性黑白），风格只体现在画面层——这样整辑视频手感统一，录屏剪辑时不跳戏。

## 虚拟时钟（整套机制的核心）

在 `<head>` 第一个 `<script>` 里劫持 `performance.now()` 与 `requestAnimationFrame`：

- 点击「启动播放」前，时间恒为 0；
- 点击后先播放 1.4s 黑场渐变，再延迟 2s 调 `window.__startPlayback()`，时钟才开始走。

为什么这样做：

1. **CSS 动画和 JS cue 走同一时钟**，永不漂移；页面加载时的字体加载、图片解码耗时全部被"藏"在黑场里，开演第一帧就是完好的。
2. **录屏友好**：录制者点完按钮有约 3.4s 余量切到录屏软件/全屏，正片从零秒干净起手。
3. **质检友好**：无头截图时把 `startReal` 回拨 N 毫秒即可"快进"到任意时刻（见 scripts/shot.js）。

## 启动流程时序

```
点击按钮 → 按钮自身 0.4s 淡出 → 600ms 后黑场层开始 1.4s 淡出
→ 2000ms 时 __startPlayback() → 虚拟时钟归零起跑
```

按钮文案「启 动 播 放」（全角空格隔开更有仪式感），下方小字提示「点击开始 · 黑场渐变后播放」。按钮是胶囊形、白色描边、透明底——任何风格的画面都压得住。

## HUD（进度条 · 时间码 · 控制）

- 默认隐藏（`body.hud-off`），鼠标移到**视口底部 60px** 内唤出，移开隐藏；`mouseleave` 也隐藏。录屏时鼠标不动就永远看不到 HUD。
- 组成：底部 5px 进度轨道（主色填充）+ 一行信息（镜头编号·标题·时长 | 时间码 mm:ss | 暂停/重播按钮）。
- 播完（DUR+2.5s）重播按钮加 `.done` 呼吸光晕，提示"可以重播了"。
- 快捷键（可选）：`R` 重播（`location.reload()`），`H` 显隐 HUD。

## 时间轴引擎

```js
const DUR=49000;                       // 本镜头规定时长，误差 ±0.5s
const cues=[],on=(t,f)=>cues.push({t,f,done:false});   // 一次性 cue
const tws=[];                          // 补间队列
const after=(ms,f)=>on(performance.now()-t0+ms,f);     // "从现在起再过 ms"（cue 内部排后续节拍用）
function tick(now){ /* 逐帧：触发到期 cue → 推进补间 → 更新进度条/时间码 */ }
```

- **cue 一次性触发**：`on(毫秒, 回调)`，按时间戳排布整镜头叙事。回调里写 DOM class 切换、补间、音效。
- **补间**：`fly(el,x1,y1,x2,y2,dur,arc,ease,done)` 抛物线飞行（硬币、卡片、弹丸），`cnt(el,from,to,dur)` 数字滚动（余额、分数、计数）。缓动 `eo/ei/eio` 常备。
- **暂停**：暂停时记录真实时刻，恢复时 `t0 += 暂停时长`，并把 `body.paused`（CSS 里 `animation-play-state:paused!important`）挂上让 CSS 动画同步停。
- **重播** = `location.reload()`，简单可靠。
- 每个 cue 写注释引用口播稿时间戳：`on(19000,...)  // 5:20「正常充值50块钱走完支付」`——这是音画对齐的施工记录，回头调时间轴全靠它。

## 舞台

- 固定 **1920×1080** 设计稿坐标，`transform:translate(-50%,-50%) scale(s)` 适配窗口（`s=min(w/1920,h/1080)`），`resize` 监听。
- 所有布局用绝对定位像素坐标（画布思维），不使用响应式单位。1920×1080 内的安全边距：左右 ≥52px、上下 ≥34px（HUD 与角注占底部）。

## 页面骨架顺序

```
<head>
  ① 播放器引导脚本（虚拟时钟 + 黑场层 + HUD 显隐）   ← 必须第一个
  ② SFX 引擎脚本
  ③ 字体 <link>（Google Fonts，随风格换）
  ④ <style>（#cam 镜头层 → 画面层 → 底盘区样式）
<body>
  #stage
    #cam > 全部画面内容
    黑边/暗角/字幕条/角注（cam 外，不随镜头缩放）
  #hud
  ⑤ 主脚本：时间轴引擎 → camTo/camFocus → 本页 cue
```
