## 一、怎么用这份文件

**三步定件：**

1. 在下面的「二十五类速查表」里，按**你要讲什么**找到类别。比如"我要讲两套方案的区别" → C06 对比·对照；"我要砸一个大数字" → C04 数据大字·单指标。
2. 在第二部分的该类详表里挑 slug，重点看「时长」和「做什么用」两列。挑中了记住 slug（就是目录名）。
3. 进 `01_动效库\itelmn\<slug>\`，按下面方式看效果。

**看效果**（⚠️ 直接双击 `index.html` **只会看到一个空白冻结帧**）：

全库 1,225 个包统一写成 `gsap.timeline({ paused: true })`，而且**没有任何一处调用 `.play()`**。叠加 `.from()` 默认的 `immediateRender`，元素一开始就被摆到"不可见"初始态，所以你不主动 seek 它就不动。这不是缺陷——**正是它适合接自建 cue 系统的原因**，但意味着不能指望"看到什么就是什么"。

| 方式 | 怎么做 |
|---|---|
| ① 控制台播一下（最快） | 打开 `index.html` → F12 → `window.__timelines[Object.keys(window.__timelines)[0]].play()` |
| ② 精确定位某一帧 | 同控制台 → `window.__timelines['t1-ov-duallist'].pause(2.4)`（单位秒） |
| ③ 现成预览副本 | `04_预览\kallaway-t1-overview-duallist.html`——已注入 autoplay，空格暂停 / `r` 回零 / `e` 播放 |

> 注意：**composition-id 不等于 slug**。例如 `kallaway-t1-overview-duallist` 的 id 是 `t1-ov-duallist`。不确定时用方式 ①的 `Object.keys(...)` 取。
> 预览副本只对「单 HTML 且不依赖 `assets/`」的包有效（859 个）；依赖本地素材的包移动路径后素材会 404，得原地看。
> 需要联网，GSAP 默认走 `cdn.jsdelivr.net`。

**四条硬约束**（详细推导见 `UI2V动效库_结合分析.md` §4 / §6）：

1. **GSAP 必须本地化**。库里有现成副本，直接从 `code-slice-hero\assets\gsap-3.14.2.min.js` 拷一份（另有 42 个包自带，共 43 个）。
2. **不要用 iframe 套**。走 `file://` 时 iframe 是不透明源，`contentWindow` 拿不到，通信和 seek 全失效。必须内联进同一个文档。
3. **只取「画面层 + 暂停时间轴」**。配色、字体、示例数字一律按自己的规范重刷，别跟着搬。
4. **禁止伪造回显**。`terminal-*` / `terminal-simulator` / `code-typing` 类会逐行打出命令与输出，要用只能借它的窗口外框（`.term-bar` 三个圆点 + 标题栏），内容换成抽象样式。

## 四、使用提醒（踩过的坑，先看这条）

**技术上**

1. **默认冻结**：全库 1,225 个包不主动 `.play()`，必须 seek（见第一节表格）。也别指望"双击就能看"。
2. **composition-id ≠ slug**：`window.__timelines` 的键是 composition-id，如 `kallaway-t1-overview-duallist` → `t1-ov-duallist`。查不到就用 `Object.keys(...)` 取第一个。
3. **别碰 403 个多文件包**：它们自带 `src/scenes/*.js` 场景引擎和构建脚本，摘取成本远高于收益。859 个单 HTML 的才是好摘的。
4. **靠 CDN 的 GSAP 会咬人**：无头 QA 遇到 CDN 抖动会直接拍出空白帧，务必本地化。
5. **`window.__hyperframes`**（346 个包在用）是官方的变量注入接口，可按参数改文案 / 配色，不必改代码。

**内容上**

6. **配色必须重刷**：库里的配色五花八门，跟你 `_可视化规范v4.md` §2.6 的实体锁色（flag 品红 / AI 青 / 风险橙红 / git 绿 / 命令行琥珀 / 隔离靛紫）全对不上。
7. **字体必须换**：库里多为 Inter / Space Mono 一类，会撞你 §2.7「每页 2–4 个 Google Fonts 且页间不重复」。
8. **数字纪律**：库里的示例数字（比如某教育模板写着"revenue targets by 24%"）**绝不能**跟着搬，全靠 §2.4 白名单自己填。
9. **禁止伪造回显（红线）**：`terminal-window` / `terminal-simulator` / `code-typing` 与 §2.5 直接冲突，只借外框不借打字逻辑。
10. **音效不要混**：库里自带的音轨和你 `__sfx` 那六个合成音是两套体系，混用会打架，只用 `__sfx`。
11. **授权**：`motions` 仓库**没有 LICENSE**，且很多包的描述里标注来源是其它社区仓库（如 `dgcruzing/hyperslides-hyperframes-educational-catalog`）。自己改着用没问题，**对外发布 / 商单前要回原站确认**。
