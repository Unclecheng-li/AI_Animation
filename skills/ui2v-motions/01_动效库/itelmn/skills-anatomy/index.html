Anatomy of a skill
skills/<name>/
(What loads, and when)
What an agent actually reads.
01 / Always loaded
--- name: <skill-name> description: what it does, when to fire ---
Two required keys. The description is the only text an agent reads when deciding whether to load the skill.
02 / Loaded when it fires
# The body When NOT to use it. Exact commands, paths. How to verify for real.
Instructions written at the agent, not about it. Kept under roughly 500 lines.
03 / Loaded on demand
reference/*.md scripts/* assets/*
Linked by relative path, so depth costs nothing until the skill reaches for it.
Frontmatter checked by scripts/validate.mjs
Progressive disclosure
