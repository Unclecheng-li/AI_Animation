# Hero Type Cascade

Three stacked headlines cascade into place with a cyan accent rule. This piece is a pure kinetic-type hero for UI2V marketing surfaces.

## Purpose

- Launch messaging and manifesto heroes
- Typography-first demos with no external assets
- Teaching staggered text reveals in HyperFrames

## Specs

- Canvas 1920x1080, 4.5 seconds, 30fps
- Entry: index.html
- Motions: line stagger, accent draw, subtle parallax drift

## Usage

Install via ui2v, scrub in preview, then publish or mount in a carousel.

## Notes

The middle line carries the primary message; keep secondary lines quieter so hierarchy stays obvious on first glance.
