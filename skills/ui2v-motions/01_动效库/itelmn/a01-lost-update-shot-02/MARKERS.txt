Shot shot_02 — required event markers (4)

Each row needs ONE element in the composition carrying that id, which becomes
visible (opacity >= 0.5) at the given time. The element can be any visual you
like — the moving object, a tick, a label, a ring. Layout is your call.

  #ev-a_read   @ 1.239s   req_a read  — A sees 100
  #ev-b_read   @ 3.153s   req_b read  — B sees the same 100
  #ev-a_write  @ 6.869s   req_a write  — A commits 90
  #ev-b_write  @  9.91s   req_b write  — B commits 80 over A
