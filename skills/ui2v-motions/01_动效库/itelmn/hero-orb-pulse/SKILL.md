# Hero Orb Pulse

Textless cyan orb blooms, rings expand, then the core pulses. Function: **energy / focus / brand void**.

## Purpose

- Background loops, loading ambience, product void states
- No typography — pure form and light
- Night slate with sky accent

## Specs

- Rings stagger in; outer rings counter-rotate
- Orb scale yoyo pulse after settle
- Entry: `index.html`

## Usage

```bash
npx hyperframes preview
ui2v motion publish . --version 1.0.0
```
