# 图表词汇表（选型 → 内容匹配 → 实现要点）

拿到一段口播先做"图表选型"：这段内容本质是什么结构？下表按内容→图表映射（左列问自己，右列用对应词汇），实现全部纯 CSS/SVG，禁外部图表库。

## 选型表

| 内容本质 | 图表词汇 | 实现要点 |
|---|---|---|
| 数量/规模/star 数 | **大字计数 + 点阵** | bignum 滚 count（配 type 连击音）；1 点=1 单位的方点阵翻倍（15→50+） |
| 多数量并列 | **发丝轴柱状** | 1px 轴线+灰阶柱（hero 柱=橙）；胶囊柱端；柱升起 scaleY + stagger |
| 随时间的数量 | **发丝刻度线/粗刻度柱** | 横轴细刻度（F2）或粗刻度块（F1）；数值标签 Inter 600 |
| 事件序列/恶化 | **横向时间线** | 1px 墨轴+节点圆点+日期标签；事故节点=橙描边；状态逐级恶化用灰阶变深 |
| 历史沿革 | **时间线+比例刻度** | 年份刻度+事件卡交替上下 |
| 循环/习惯 | **环形回路** | 圆形布局四站（白卡节点+墨圈编号），1.5px 墨弧线 draw 描线，中心墨底反白核心；出口→结论 |
| 流程/链路/供应链 | **流程链 flow** | 白卡节点横/纵排列，节点间发丝实线（**不是发光箭头**）+独立 polygon 箭头；粒子=小墨点沿线 fly |
| 分支/决策 | **流程图+判定菱形** | 菱形描边节点+是/非发丝分支 |
| 状态迁移 | **状态机弧线** | 状态白卡+弧线箭头（改坏/回退标签） |
| 对比/二分 | **双列对照** | 左右硬分割二分栏，两栏标签/条目镜像，底部一句结论；或 slopegraph 两状态连线 |
| 三方角色交互 | **泳道** | 三条横向泳道（角色名左标签），消息发丝线+时序编号 |
| 对话/调用 | **时序图** | 生命线 1px 墨虚线+消息箭头+ALT 片段框 |
| 包含/隔离/层级 | **嵌套框** | 大框套小框，隔离边界描粗（2.5px 墨），内框清单 chip；或分层堆叠侧视 |
| 结构组成 | **分层堆叠** | 三层横条堆叠+左侧层名，发丝线分隔 |
| 权限/能力矩阵 | **网格矩阵** | 行列白卡，点亮=墨底反白，焦点格=橙 |
| 分布/密度 | **热力矩阵** | 灰阶明度=数值，焦点格橙描边 |
| 多选一收敛 | **金字塔/漏斗** | 三块收敛为一，发丝线+箭头 |
| 清单/计票 | **计票清单** | 逐条打勾（墨底反白 ✓ 卡），计数右对齐 tabular-nums |
| 命令/代码/路径 | **墨底终端卡** | .dark 卡+IBM Plex Mono；抽象行块（不写真实回显）；`~/` 等关键 token 橙标 |
| 操作步骤 | **编号步骤卡** | node-num 编号+白卡+键帽 .key（Ctrl/C 等用键帽图形） |
| 前后对照 | **双态并排** | 坏=橙描边，好=墨；或左右两卡+中间箭头 |

## 实现纪律

- 图表骨架（轴线/网格/刻度）= `--grid`/`--faint` 发丝线；数据主体 = 灰阶阶梯（明度即数据）；**唯一主角 = 橙**；
- SVG 描线用 `.fx-draw`（stroke-dasharray 技巧）；dash 隐藏路径上的箭头会提前渲染 → **箭头用独立 polygon**；
- 计数滚动 = tws 线性 + type 连击；柱升起 = transform-origin:bottom scaleY；
- 图表内文字：轴标签 Inter 600 uppercase·14px·灰；数值 Inter 800 tabular-nums；
- 主视觉 ≥55% 面积——图表是主角，不是插图。

## 与拟真仿真共存（B 类页）

真机/软件界面仿真的**内容结构原样保留**（窗口/面板原生配色不动）；只把**舞台底、页头、标注引线、角注、结论条**换成瑞士系统（纸灰舞台/Inter/墨底反白标注/橙焦点）；仿真窗口不叠任何光效。示意页标「示意图 · 非实拍」。
