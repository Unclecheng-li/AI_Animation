# 手机舞台：真机细节与 3D 姿态系统

真机感是本 Skill 的生命线。手机不是"画了个框"，而是一台有材质、有细节、**有姿态的活设备**。

## 手机解剖（全系列统一规格）

| 部件 | 规格 | 实现要点 |
|---|---|---|
| 机身 `#bez` | 412×868，圆角 60px | 三段渐变（#2b2f3a→#14161d→#1e222c）+ 内阴影双圈（高光 1px + 深腔 22px）|
| 屏幕 `#scr` | 390×846，圆角 48px | `overflow:hidden` 裁切一切屏幕内容；内圈 1.5px 白描边 + 底部微暗弧 |
| 挖孔 `#punch` | 13px 居中，top 24px | 径向渐变镜头腔 + 3.5px 蓝色反光点 + 黑色加厚环 |
| 侧键 `.kbtn` | 电源右 88px / 音量左两条 54px | 4px 宽渐变金属条，凸出机身 3.5px |
| 天线带 `.kant` | 上下边内 5px，左右留 30px | 2.5px 半透明白条 |
| 背光 `#phoneGlow` | 600×1020 径向渐变 | z-index:-1，颜色随本镜壁纸主题 |
| 反光 `#glare` | 对角高光带 | linear-gradient 118deg，5% 白的两条亮线扫过屏幕 |
| 投影 | drop-shadow(0 46px 80px) | 手机悬浮于舞台之上的重量感 |

**状态栏 `#sb`**：左侧时间（tabular-nums，演示时间可用 09:41 经典梗）+ 右侧信号格/Wi-Fi/电池三枚内联 SVG（`currentColor` 驱动）。**进入浅色 App 页面时 `body.sb-dark` 整体切深色**（状态栏文字 + Home 条同步过渡 .4s）。Home 指示条 134×5px 白条底部居中。

## 壁纸系统

```css
.wall{inset:-24px}              /* 外层：鼠标视差 ±6px（mousemove 驱动） */
.wallIn{animation:kb 16s infinite alternate}  /* 内层：Ken Burns 缓慢缩放漂移 */
```

- 每镜头一组**主题渐变**（3–4 层 radial + 1 层 linear，亮斑左上/右中/底部深色），相邻镜头色系不同；
- 全系列**实体颜色锁定**（主角功能=固定色、危险=红…），靠壁纸变化 + 锁定色维持既统一又可追踪；
- App 打开转场时壁纸加 `.blurred`（blur 22px + saturate 1.3 + 微放大）；
- `#wake`：纯黑遮罩，开演 400ms 淡出 = "亮屏"动作。

## phoneTo：3D 姿态系统（手机的表演功）

```js
const P={ry:0,rx:0,rz:0,s:1,ty:0,op:1};      // yaw偏航/pitch俯仰/roll横滚/缩放/升降/透明
function phoneTo(patch,dur){Object.assign(P,patch); /* 写 transition + transform */}
```

`#cam` 上 `perspective:1900px` 提供透视。**实测动作词汇表**：

| 动作 | 参数 | 用在 |
|---|---|---|
| 登台（仅首镜头） | `{ry:-24,rx:5,s:.9,ty:70}` → 配合 `.in` 淡入 → `{ry:0,rx:0,s:1,ty:0}` 1.3s | 全系列唯一一次手机"出现" |
| 初始姿态 | `on(0,phoneTo({ry:-7,rx:2},0))` | 非首镜头开帧即有姿态（接续上镜余韵）|
| 灵动摇摆 | `{ry:±4~10}` 0.9s | 通知滑入、选项选中、气泡到达——**手机的"点头回应"** |
| 点按前倾 | `{rx:3.5,s:1.015}` 0.5s | 用户点按图标/按钮瞬间，强调交互发生 |
| 强调推进 | `{rx:3,s:1.02~1.03}` 1.0s | 关键结论/盖章时刻（配合 camFocus）|
| 横屏 | `{rz:-90}` 1.5s + 屏幕内容横版设计 | 仪表盘/宽表格类镜头 |
| 震动 | rx 快速 ±2 三连（140ms 间隔） | 盖章冲击、错误反馈 |
| 旋走退场 | `{ry:26,rx:9,rz:-4,s:.52,ty:48,op:0}` 2.4s | 收尾镜头熄屏后"3D 远去" |

**与镜头调度的配合**：`camFocus` 推近 + `phoneTo` 前倾同帧触发=双重强调；但**幅度收敛**（scale ≤1.06），否则手机出画压到两侧大字幕。手机姿态变化自带小音量 whoosh(.38)。

## 连续性铁律（用户迭代出的核心规则）

1. **整辑统一舞台氛围**：`#amb` 深靛蓝渐变+网格+噪点全系列一个字不改（需要突出屏幕时可 `.dim` 压暗到 16%）；
2. **首镜头才有登台动画**；其余镜头 `#phone` 默认可见（删掉 `opacity:0`），开帧只有"接续上镜余韵"的初始姿态；
3. 相邻镜头初始姿态方向**呼应上一镜结束姿态**（上镜结尾左偏 → 本镜初始 `{ry:-7}` 再缓缓回正）。
