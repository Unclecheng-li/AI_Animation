# medical-tabs

Tabbed layout. Tab buttons cycle through active states; content area shows matching panel.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "Clinical Decision Framework" |
| tabs | JSON string | Array of {label,icon,heading,body} |
| primaryColor | color | #285f9f |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-blue.png |
| durationPerTab | number | 5 |

**Note:** template name is "medical-tabs" but content is fully rebrandable — works for any domain.
