# 视频分镜演示动画（每镜头一个 HTML）

把一个视频项目的分镜，做成一辑**可以直接全屏录屏当成片用**的网页动画：一个镜头 = 一个独立 HTML，统一播放器手感，但每页一套完全不同的视觉风格。本 Skill 内容开放——演示什么都行（技术实测、产品发布、课程讲解、故事叙述）；不变的是**电影化机制、镜头语言与完成度标准**。

## 创作哲学（先读这个，它决定一切产出质量）

1. **风格是轮换的，不是品牌**。连续两个镜头绝不同风格。每页问自己："这个内容如果是一张海报/一个物件/一种印刷品/一个场所，它是什么？"——复古报纸、便利店 POS 小票、武功秘籍、机场安检、像素游戏……把抽象内容**具象成一个世界观**，页面就活了。
2. **禁用默认科技暗色**。黑底 + 霓虹发光 + 玻璃拟态的"乌漆墨黑油光锃亮"风是最大败笔：第一页惊艳，第三页疲劳，第五页廉价。除非内容本身是终端/黑客主题，否则不用。
3. **想象力 > 规范**。在拿到播放器机制这套"底盘"之后，画面层请放开写：意想不到的隐喻、实体的机械结构、会砸下来的印章、会掉进存钱罐的硬币。用户要的是"惊喜感"。
4. **完成度是纪律**：每个元素都有入场动画、有退场或定格；没有重叠遮挡；没有孤儿元素；结尾有重播暗示；数据有出处角注。半成品比朴素更糟。
5. **音画同步**：每个关键动作配 WebAudio 合成音效，镜头移动配 whoosh。安静也是设计——不是每毫秒都响。

## 工作流

### 第 0 步 · 理解输入与准备素材

先找并通读用户视频项目的素材（常见：`大纲.md`、`口播稿.md`、`画面设计.md`，或用户口述/贴文/截图）。要拿到三件事：

- **分镜列表**：每个镜头讲什么、时长多少秒；
- **口播稿**：每句台词的时间戳——它是动画时间轴的对齐基准；
- **素材**：角色表情包、Logo 图标、数据截图等。

本 Skill 自带素材库与实例库（`assets/`）：

- `assets/examples/` — **两套完整成片实例**（每个文件夹自包含，直接双击 index.html 即可运行）：
  - `glm-5.3-range-test/` — 29 镜头 · 安全实测复盘（复古报纸/嘉年华老虎机/像素游戏/审讯室/机场安检…）+ 播放器原始参考 `reference/0-1-typewriter.html`
  - `doubao-paper-detective/` — 11 镜头 · 论文阅读商单「论文侦探」（黑色电影档案/黄铜天平/集换式卡牌卡册/地铁线路图/毕业寄语明信片…）
- **表情包与图标**：每个项目文件夹内自带 `anan - emotion rename/`（安安 15 张情绪立绘）与项目图标（`icons/GLMicon.png`、`doubaoicon.png`、`doctor_ava.jpg` 等）。新项目开工时，把要用的素材整个复制进用户的输出目录，页面内以 `anan - emotion rename/12_粉颊捧笺_娇羞雀跃.png` 这样的相对路径引用；有新角色 Logo 就照此补充。情绪→场景速查表见 `references/character-reactions.md`。
- 它们是所有风格的"活样板"：写某种风格前，先读 1-2 个同风格的成片页学其落地手法（风格↔页面对应关系见 `references/style-library.md` 的索引，或直接打开各项目 index.html 看风格标签）。两套实例也演示了同一底盘如何服务完全不同的内容领域。

素材不全时，先列出分镜表（编号/标题/时长/口播段落）让用户确认，再动手。没有口播稿就自己按内容节奏排时间轴，并在代码注释里注明每个 cue 对应的叙事节拍。

### 第 1 步 · 风格分配表（动工前必做）

为全部镜头排一张表：`镜头 | 时长 | 视觉风格 | 字体组合 | 主色`。规则：

- 相邻镜头风格不同；整辑内尽量不重复（29 个镜头可以 29 种）；
- 每种风格对应**它最擅长的内容类型**（清单见 `references/style-library.md`）；
- 全系列一致性：**同一实体在全系列锁定同一颜色**（如 A 模型=电青、B 模型=琥珀金、危险=红），观众靠颜色跨页追踪角色——这比每页换色高级得多。

把表给用户过目（一次确认，避免整批返工），然后逐页实现。

### 第 2 步 · 逐页实现

**从 `assets/template.html` 复制起步**——它已内置全部底盘（虚拟时钟播放器、音效引擎、1920×1080 舞台、镜头层、时间轴引擎、HUD、字幕条、角色位）。然后：

1. 换字体（Google Fonts，与风格匹配）与配色，重画画面层；
2. 按口播时间戳写 cue（每个 cue 注释引用口播句，如 `// 5:20「正常充值50块钱」`）；
3. 布置镜头调度（见下"镜头语言"）与音效 cue；
4. 时长 `DUR` 必须等于该镜头规定秒数，误差 ±0.5s。

子系统细节按需读：

- `references/player-system.md` — 黑场启动/虚拟时钟/HUD/时间轴引擎/暂停重播的原理与定制
- `references/camera.md` — camTo/camFocus、开场拉镜、跟拍、慢放黑边等镜头语言
- `references/sfx.md` — WebAudio 合成音效引擎、cue 记法、配乐原则
- `references/style-library.md` — 风格库（29 种实例+适用内容）、字体配对、反模式
- `references/character-reactions.md` — 角色表情特写、吐槽气泡、字幕条同步规范

### 第 3 步 · 质检（每页必做，录屏前最后一关）

用 `scripts/shot.js` 在多个时间点无头截图（机制：虚拟时钟可直接快进到任意毫秒）：

```bash
node scripts/shot.js 页面.html 5000 _t5s.png          # 5s 处
node scripts/shot.js 页面.html 12000 _t12s.png 960 540 1.2   # 12s 处 + 相机锁定在推近态
```

逐张检查：**重叠遮挡**（文字压文字、气泡出画面）、**完成度**（该出现的元素出现了吗）、**动画状态**（中间态是否穿帮）、**收尾帧**（结尾定格是否体面）。发现问题回改再截。最后亲自打开页面完整播一遍。

### 第 4 步 · 总览页 index.html

做一张与正片风格一致（但自成一种风格）的总览：按章节分组、卡片列出每页（编号/时长/标题/**风格标签**），标注角色色锁定与数据出处。它既是导航，也是给用户验货的清单。

## 改造升级已有演示页时

当用户给的是一批已有页面要"翻新"（而非从零写）：

1. 先盘点：哪些页风格撞车/动效贫乏/完成度低——列清单给用户，**用户点名保留的页面一个字符都不要动**；
2. 底盘统一：把 template 里的播放器引导脚本/音效引擎/镜头层注入要改的页（替换各自为政的旧播放器）；
3. 再逐页重设计画面层（同风格分配表流程）；
4. 补角色反应、镜头 cue、音效 cue，最后走第 3 步质检。

## 交付标准（缺一即未完成）

- [ ] 黑场 + 「启动播放」按钮起手，点击后 2s 黑场渐变再开演
- [ ] 1920×1080 舞台自适应缩放；HUD（进度条/时间码）默认隐藏，鼠标移到画面底部唤出
- [ ] 可暂停/重播；播完出现重播暗示
- [ ] 每页独立时钟，刷新即重置；DUR = 规定时长
- [ ] 每页风格、字体组合、配色与前后页不同；无默认科技暗色
- [ ] emoji 一律换扁平 SVG 图标
- [ ] 关键节拍有镜头运动（推/拉/跟/摇）+ whoosh
- [ ] 关键动作有音效；计数滚动有连击键音
- [ ] 有角色表情特写 + 吐槽气泡（有素材时），淡入登场；气泡**必须用统一强约束模板**（形态锁定，仅 4 个配色参数按页面调整，见 `references/character-reactions.md`）
- [ ] 字幕条与口播逐句同步，关键词高亮
- [ ] 无重叠遮挡（截图验证过）；数据角注出处
- [ ] index.html 总览可逐页打开
