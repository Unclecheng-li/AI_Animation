# contrasting-grid

Responsive grid of cells. Each cell animates from showing a large number to revealing its heading and body text.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "Project Constraints: Key Tensions" |
| items | JSON string | Array of {number,heading,body} (2–9 items) |
| primaryColor | color | #285f9f |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-blue.png |
| durPerItem | number | 3 |
