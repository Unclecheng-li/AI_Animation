# 内容替换清单

1. 修改 `index.html` 中带有 `YOUR SYSTEM`、`[工具 A]`、`YOUR DATE`、`YOUR ASSET` 的文字。
2. 替换 `assets/89798.mp4` 为你的主录屏，或保留它作为背景素材示例。
3. 替换 `assets/call_KD5k5BSq7NIqfBncBKAavIyb.png` 为你的海报/封面图。
4. 替换 `assets/echoid-background.mp4` 为新的背景视频。
5. SFX 位于 `assets/sfx/`；原视频的音效轨道已保留，替换文件时尽量保持文件名或同步修改 `<audio>` 的 `src`。

不要删除原有的 `.morph-text`、`.glass`、`.note`、`.recording-card` 等结构，它们就是 8-16 的效果组件。
