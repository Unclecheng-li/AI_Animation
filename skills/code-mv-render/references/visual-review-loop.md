# Claude Motion：可视审查闭环

来源：[whaleyxbt/claude-motion](https://github.com/whaleyxbt/claude-motion)（MIT）的 `.claude/skills/review-loop/SKILL.md`。核心原则：**不能靠阅读代码想象运动，必须看当前渲染的帧。**

## 五层审查

| 层级 | 输出 | 检查重点 |
|---|---|---|
| 全片 contact sheet | 每个镜头/beat 的落定帧，带时间戳 | 视觉弧线、章节比例、 focal point、空帧、颜色与元素一致性 |
| 关键动作时间带 | 转场/动作前后密集采样 | 碰撞、突跳、入场/出场关系、空帧、速度与方向连续 |
| 精确静帧与 1:1 裁切 | 指定 `t` 或帧号、全分辨率局部 | 表情、文字裁切、细线、材质、接触关系、安全区 |
| 最终 MP4 解码 sheet | 从实际编码文件抽帧 | 编码后画面、接缝、首尾帧、字幕与音画同步 |
| 音频波形/指标 | waveform/spectrogram、RMS、LUFS、true peak | 瞬态落点、异常静音、对白避让、响度与峰值 |

关键帧可选取节拍/镜头点后约 0.3 秒的落定状态，同时保留切点本身，避免只看到稳定状态而漏掉中间穿帮。

## 固定循环

```text
草稿渲染 → 全片 sheet → 逐张打开检查 → 定位可疑时间
→ 时间带 / 1:1 裁切 → 修复源头 → 重渲当前版本
→ 对比前后 → 全片复核 → 最终 MP4 解码帧 + 音频复核
```

每次修改视觉或时间后都重做受影响层级的检查。不要拿旧 sheet 验收新代码；不要声称看过未实际打开的图片或听过未实际试听的音频。

## 检查表

### 构图

- 每帧一个主焦点；两个信息竞争时，让一个等待。
- 进出元素共享空间时没有非预期遮挡；重要内容处于目标平台安全区。
- 第 0 帧是可用的真实画面，结尾按 brief 稳定收束。

### 字体与信息

- 文字不被 mask、容器或画幅误裁；手机尺寸仍能读核心信息。
- 阅读期间文字停稳，阅读时长足够；数字、字幕、口播与声音事件一致。
- 颜色仅来自当前 palette，强调色对应当前重点；同一实体跨镜一致。

### 运动与时间

- 动作有预备、跟随与合理速度；不存在非预期冻结、闪帧和单帧离群。
- 可读状态保持足够时间；镜头切换不经过空白中间态。
- 出场通常比入场更快；具体时长由语义和平台决定，不机械套值。

### 声音

- 瞬态与画面事件/节拍对齐，不只按 BPM 猜位置。
- 目标可参考约 −14 LUFS ±1、true peak ≤ −1 dBFS；实际按平台与 brief 调整。
- 自动测量不等于听审，无法听音时明确报告这一限制。

## 本库执行方式

现有工程使用本地脚本，不假设上游 npm scripts 已安装：

```bash
node templates/qa-stills.mjs --page examples/cve-100k/demo.html --times 13.6,24.6,46,59.5,79,86.5 --out ./qa
node templates/qa-stills.mjs --page examples/cve-100k/demo.html --range 0..90 --step 5 --out ./qa_all
```

最终成片可再用 FFmpeg 从 MP4 抽 sheet，用 `video-qa-frameproof` 做空帧、冻结、字幕、音频和回归检查。自动工具与人工看图相互补充。

## 完成报告

报告：检查了哪些 sheet/时间段、修复了什么、对应的新证据在哪里；同时列出未解决项与未覆盖范围。只有当前版本全轮检查无未解释问题，才可称为完成。
