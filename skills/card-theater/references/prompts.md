# Card Theater — Prompt 参考

## 1. 基础生成

```
用 card-theater 制作一个关于「{主题}」的演示，{N} 张卡片，{模板名} 模板
```

```
用 card-theater 演示 {概念/流程/协议}，需要模式切换（{模式A} / {模式B}）
```

## 2. 模板指定

```
以 assets/coverflow-classic.html 为模板，演示 {主题}
```

```
用 apple-aurora-track 风格展示 {主题}，{N} 张卡片
```

```
用 coverflow-focus 模板，由浅入深讲解 {主题}
```

## 3. 内容规划

```
用 card-theater 制作 {主题} 演示：
卡片1: {标题} — {解说要点}
卡片2: {标题} — {解说要点}
...
模式切换: {模式A} ↔ {模式B}（{模式B} 多一张 {额外卡片标题} 卡片）
```

## 4. 风格调整

```
用 card-theater 演示 {主题}，要求：
- 配色用 {蓝色/绿色/紫色} 系
- 卡片宽度 {N}px
- 侧边栏在 {左/右} 侧
- 高亮颜色: {颜色}
```

## 5. 动画细节

### 荧光笔高亮
```
每张卡片的关键字段用荧光笔高亮效果，选中时从左到右划过
```

### 水印图标
```
每张卡片背景放一个巨型半透明图标作为装饰，选中时透明度增加
```

### 3D 倾斜
```
鼠标移动时卡片跟随做 3D 透视倾斜，灵敏度适中
```

### 总结卡片
```
最后加一张总结卡片，列出所有步骤的 checkmark 清单
```

## 6. 模式切换实现

### 基本模式切换
```
添加一个模式切换按钮，点击后动态显示/隐藏第 {N} 张卡片
切换时自动滑动到新卡片，侧边栏文字同步更新
```

### 双模式完整版
```
两种模式各有不同的卡片数量和解说内容：
- {模式A}: {N} 张卡片，解说侧重 {要点}
- {模式B}: {M} 张卡片，解说侧重 {要点}
按钮文字随模式切换，指示器变色
```

## 7. 常见主题模板

### 协议流程
```
用 card-theater 演示 {协议名} 工作流程：
1. {步骤1} — {说明}
2. {步骤2} — {说明}
3. {步骤3} — {说明}
4. 安全层 — {说明}
（可选）5. 隧道封装 — {说明}
```

### 产品特性
```
用 card-theater 展示 {产品名} 的 {N} 个核心特性：
每张卡片一个特性，包含图标、特性名、技术描述、关键指标
```

### 攻击链
```
用 card-theater 演示 {攻击名} 攻击链的 {N} 个阶段：
从初始侦察到最终目标，每张卡片一个攻击阶段
```
