# 系统 UI 组件库与内容转译

## 核心法则：一切信息都是"手机里发生的事"

写任何镜头前先问：**这段内容在真机上是什么交互？** 禁止普通网页元素（普通段落/按钮/导航栏）进屏幕。转译映射表：

| 原始信息 | 转译成系统场景 | 组件要点 |
|---|---|---|
| 关键论点/要点 | **锁屏通知**逐条滑入 / 任意界面顶部**通知横幅** | App 图标(超椭圆渐变)+标题+一句摘要；stagger 60-80ms，从上方 -26px 缩放入 |
| 对话/问答/引用 | **聊天界面**：先"三个点"打字指示器，再气泡弹出 | 区分对方/自己左右 + 时间戳 + 已读标记 |
| 数据/百分比 | **环形进度**从 0 绘制 / 控制中心**滑条** / 大数字滚动 counter | stroke-dashoffset 绘制；counter 配 TnE 连击键音 |
| 流程/步骤 | **设置列表**逐条点亮 / "正在配置…"**系统进度弹窗** | 列表行左图标右箭头，逐条点亮 |
| 对比/选择 | 底部弹出 **ActionSheet** 大按钮组 | 依次弹入，主按钮主题色 |
| 警示/反例 | **系统弹窗**（红色主按钮）/ 低电量 / 权限请求风格 | 半透明遮罩 + 居中卡片 + 毛玻璃 |
| 列表/收藏 | 主屏 **App 网格**（超椭圆图标 stagger）| 渐变底 + 白色符号 |
| 总结/号召 | 结尾回**锁屏**：超大时钟 + 一句话副标题 → **熄屏** | 熄屏后手机 3D 旋走 + 品牌落幕卡 |

信息密度纪律：**一个镜头 = 一句话 + 一个视觉主体**。像真录屏，不是 PPT。

## HyperOS / MIUI 设计语言（全系列统一）

1. **形状**：大圆角哲学——卡片 24–28px、按钮/开关胶囊形、控制中心磁贴 2×2 大圆角、App 图标超椭圆（border-radius 24%–28%）。
2. **材质**：层级+毛玻璃——系统面板 `backdrop-filter:blur(24px) saturate(1.6)` + 半透明白/黑；内容卡片微渐变纯色 + 柔和大阴影（0 8px 24px rgba(0,0,0,.10)）。忌硬描边、忌大面积玻璃堆叠。**毛玻璃层级 ≥2 层**（壁纸→玻璃面板→内容卡片）。
3. **排版**：MiSans/-apple-system/HarmonyOS Sans/PingFang SC 字体栈；层级靠字号字重跳跃——超大数字/时钟 72–96px w200、标题 28–34px w700、正文 15px w400、辅助 12–13px 灰。数字一律 `font-variant-numeric:tabular-nums`。
4. **图标**：全部内联 SVG 单色线性（24 网格、2px 圆头描边）；App 图标=渐变底超椭圆+白色符号。**无真实品牌商标**（虚构 App 名）、**无 emoji**。
5. **缓动**：弹性入场 `cubic-bezier(.34,1.56,.64,1)`；位移/淡入 `cubic-bezier(.22,1,.36,1)`；时长 350–600ms；列表 stagger 60–80ms（下方 16px 滑入）。

## 标志性转场：App 打开动画（图标放大铺满）

整辑**至少出现 1 次**（通常是镜头 2），系统级的"打开 App"morph：

```css
#appWin{left:36px;top:314px;width:62px;height:62px;border-radius:17px;  /* 起点=图标精确位置/尺寸/圆角 */
  transition:left/top/width/height/border-radius .68s cubic-bezier(.32,.72,.35,1)}
#appWin.open{left:0;top:0;width:390px;height:846px;border-radius:48px}   /* 终点=满屏 */
#appInner{left:-36px;top:-314px}   /* 内容层反向补偿，窗满屏时内容正好归位 */
#appWin.open #appInner{left:0;top:0;opacity:1}  /* 窗扩大同时内容淡入 */
```

配合：图标先 `.tap` 按压效果 + 手机点按前倾 → 窗 morph 铺满 + 壁纸 `.blurred` 加深 + whoosh。反向做退场。

## 其他高频组件实现要点

- **锁屏**：顶部小锁图标 → 日期 17px + 时钟 92px w200 → 通知堆叠区 → 底部手电/相机快捷圆钮 + "向上滑动以解锁"。
- **解锁**：锁屏层 translateY(-100%) 上移 + 略缩放淡出，主屏从下方 6% 缩放顶上来；手机顺势摆动。
- **聊天气泡**：对方=左白玻璃、自己=右主题色；打字指示器三点跳动 800ms 后替换为气泡；气泡内容支持公式（斜体/等宽）。
- **判题盖章**：红色"正确✓/错误✗"圆章 scale 2.2→1 砸落 + 手机震动三连 + thud。
- **知识图谱/星云**：SVG/DOM 节点 + 连线；多级下钻用层级容器 scale 缩放切换 + 面包屑；脉冲动画做"活跃节点"。
- **控制中心**：2×2 磁贴网格 stagger 缩放弹入；亮度/音量粗竖条滑块。
- **CTA 呼吸**：主按钮 2.2s 无限脉冲微缩放，引导视线。
