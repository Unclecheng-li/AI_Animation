STATUS: OPTIONAL CAPABILITY REFERENCE — NOT USED BY THE PUBLIC DEMO

The official 12-second CutSteward launch demo is music-led, with concise English
on-screen copy for international English-speaking audiences. It has no narration
or spoken dialogue by user direction. No speech-generation request belongs to
this release. CutSteward's optional Gemini TTS helper remains available for a
different project only when that project's user explicitly requests voice.
