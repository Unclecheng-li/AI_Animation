# executive-summary

Cards layout. Each card expands in turn to show detail text. Non-active cards show icon + label only.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "Executive Summary" |
| cards | JSON string | Array of {icon,label,heading,detail} |
| primaryColor | color | #285f9f |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-blue.png |
| durPerCard | number | 4 |
