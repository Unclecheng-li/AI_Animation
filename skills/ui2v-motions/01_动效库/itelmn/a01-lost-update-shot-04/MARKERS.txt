Shot shot_04 — required event markers (7)

Each row needs ONE element in the composition carrying that id, which becomes
visible (opacity >= 0.5) at the given time. The element can be any visual you
like — the moving object, a tick, a label, a ring. Layout is your call.

  #ev-a_read    @   2.5s   req_a read
  #ev-b_lock    @  3.75s   req_b acquire  — blocked — A holds it
  #ev-a_write   @     6s   req_a write
  #ev-a_unlock  @  7.25s   req_a release  — barrier lifts, B proceeds
  #ev-b_read    @     9s   req_b read  — B reads what A actually committed
