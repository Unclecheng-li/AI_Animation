# 定制 Lemo 风格

适用于“把某个库风格改成我的版本”或“从空白建立一种风格”。完整规则以[上游 MY-STYLES.md](https://github.com/lemomo-ai/lemo-opuscar/blob/main/MY-STYLES.md)为准。

## 两个入口

- **改已有风格**：先定位 `slug`，将风格属性分为放心改、改后易变味、不能改三组，再讨论修改项。
- **从空白创建**：收集用途、参考图/片与期望感受，从库中选择最接近的技法底子并解释原因；用户可更换底子。

## 五个阶段

1. **确定方案**：用途、平台、画幅、品牌色、logo、字体、固定角色、运动和声音。每轮改造已有风格时聚焦少量关键变化，避免失去风格本质。
2. **汇总并确认**：列出修改前后、视觉收益与实现代价。得到用户同意后才写成规范。
3. **输出风格图**：必须用真实绘制代码，不用文字描述或生图替代。改已有风格时可并列原图和新图供比较。
4. **制作 15–30 秒 demo**：每项关键改动都在片中出现，配好音乐/音效；先自检并修一轮，再交用户。
5. **用户决定固化**：只有用户明确同意才保存到 `~/lemo-my-styles/<名字>/`。否则保留在本次项目内继续修改或不固化。

## 检查点

- 配色与字体可改，不代表材质逻辑、镜头语法和风格识别特征都能随意改。
- 品牌 logo 按用户动画要求保留可见性；不使用 emoji 替代平面 UI 图标。
- 个人风格目录包含风格说明、改动记录、demo 与源码；更新或卸载上游插件不应删除它。
- 公开分发参考图、demo 或成片前，分别检查用户素材、第三方素材和 Lemo 示例的授权。
