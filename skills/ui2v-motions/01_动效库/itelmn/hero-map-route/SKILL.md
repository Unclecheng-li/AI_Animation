# Hero Map Route

A light mint map card draws a delivery route from Origin through Hub to Arrive. Function: progress along a path, useful for logistics and onboarding journeys.

## Purpose
- Shipping, travel, and funnel metaphors
- Step completion without checklist UI
- Light-theme variety among dark heroes

## Specs
- Route progress width animates 0 to 100 percent
- Nodes pop with back.out as milestones land

## Usage
Publish via ui2v after lint. Scrub midpoints to verify node timing.

## Notes
Keep labels short so the diagram stays cartographic.
