# Hero Avatar Stack

Warm orange avatars land in an overlapping stack while the online count rises. Function: **collaboration / presence / team**.

## Purpose

- Shared docs, multiplayer, and invite heroes
- Staggered back.out entrances
- Soft apricot field

## Specs

- Five avatars enter 0.35s apart
- Meta line updates with each arrival
- Entry: `index.html`

## Usage

```bash
npx hyperframes preview
ui2v motion publish . --version 1.0.0
```

## Notes

Keep the +N chip last so the stack reads as people first, overflow second.
