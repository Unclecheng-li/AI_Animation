## 怎么看效果（关键，不然会以为库是坏的）

**双击 `index.html` 是看不到动画的。**

全库 1,225 个包统一写成 `gsap.timeline({ paused: true })`，而且**没有任何一处调用 `.play()`**。叠加 `.from()` 会把元素先摆到"不可见"初始态，所以你打开只会看到一个近乎空白的冻结帧。

三种看法：

1. **控制台播一下（最快）** — 打开 `index.html` → F12 → 粘贴：
   ```js
   window.__timelines[Object.keys(window.__timelines)[0]].play()
   ```
2. **精确定位某一帧** — 同控制台，单位是秒：
   ```js
   window.__timelines['t1-ov-duallist'].pause(2.4)
   ```
3. **用 `04_预览\` 里的副本** — 双击即播：空格暂停/继续，`r` 回到 0 帧，`e` 播放。
   （注意：注入 autoplay 的副本只对「单个 HTML 且不依赖 `assets/`」的 859 个包有效；依赖本地素材的包一旦移动路径素材就会 404，只能原地看。）

都需要联网 —— GSAP 走 `cdn.jsdelivr.net`。

> 这个"默认暂停"不是缺陷，恰恰是它适合接进 cue 时间轴的原因：节奏完全由调用方决定。

## 怎么接到自己的演示视频里

动效包 = 「单文件 HTML + 一条 paused 的 GSAP 时间轴」，和自建底盘同构（时间驱动、可冻结、1920×1080，其中 1,150/1,262 个正好是这个尺寸）。

**推荐做法：摘它的画面层 + 暂停时间轴，挂到自己的 cue 系统上。**

```js
const TL = window.__timelines['t1-ov-duallist'];
TL.pause().time(0);

// 整段映射：把 4 秒动效摊到 12 秒贴合口播
on(2600, () => {
  tws.push({ t: 2600, d: 12000, e: eo, f: p => TL.time(p * 4.0) });
});

// 或按口播拆拍
on(2600,  () => TL.time(0.0));   // 「先看这张表」
on(7800,  () => TL.time(1.6));   // 「左边这一栏」
on(12400, () => TL.time(3.1));   // 「右边这一栏」
```

四条硬约束：

1. **GSAP 必须本地化**到项目 `_vendor\gsap.min.js`。项目规范禁止外链，且无头 QA 遇 CDN 抖动会拍出空白帧。可直接拷 `01_动效库\itelmn\code-slice-hero\assets\gsap-3.14.2.min.js`（库里有 43 个包自带本地副本）。
2. **不要用 iframe** 套。`file://` 下浏览器把 iframe 当不透明源，`contentWindow` 取不到，seek 会失效。必须内联进同一个文档。
3. **进来先 `.pause()`**，并确认 QA 冻结核路径上没有漏掉的 `.play()`。
4. 720p 的包要按 1.5 倍等比放大字号与间距。

挑包时的硬过滤：**要 1920×1080**（1,150 个符合）；1080×1920 / 720×1280 的竖屏 112 个直接排除。

## 红线

- **`terminal-window` / `terminal-simulator` / `code-typing` 这类会逐行打真实终端回显**，与「禁止伪造终端回显」的规范直接冲突 —— 只能借窗口外框（三个圆点 + 标题栏），弃掉打字逻辑。
- 包里的示例数字（如模板写死的 "revenue targets by 24%"）**绝不能跟着搬**，自己按白名单填。
- 配色、字体都要按项目规范重刷（包自带的多是 Inter / Space Mono 一类）。
- 403 个多文件包自带 scene 引擎和构建脚本，摘取成本远高于收益，别碰。
- **`motions` 仓库没有 LICENSE**，且动效描述里大量标注来源是其它社区仓库。自己改着用没问题，**对外发布 / 商单前必须回原站确认授权**。
- 包自带音轨与项目 `__sfx` 是两套体系，混用会打架，只用 `__sfx`。
