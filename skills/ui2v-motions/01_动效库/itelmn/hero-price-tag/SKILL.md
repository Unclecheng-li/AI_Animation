# Hero Price Tag

A hanging orange price tag drops on a string and swings to rest on a discounted figure. Function: **commerce / offer reveal**.

## Purpose

- Pricing and launch-offer heroes
- Physical pendulum settle (rotate around hang point)
- Warm paper store aesthetic

## Specs

- Tag transformOrigin is left-center near the eyelet
- String draws first, then the tag swings
- Entry: `index.html`

## Usage

```bash
npx hyperframes preview
ui2v motion publish . --version 1.0.0
```

## Notes

Keep the struck-through price readable. Tiny original prices disappear at thumbnail size.
