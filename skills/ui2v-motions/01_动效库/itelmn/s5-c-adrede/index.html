EL MERCADO
POR DINERO
Ellos, miren, ustedes
saben que el mercado
capitalista está aquí
por dinero, ¿no?
Entonces, ellos tienen
un programa o un modelo
de tal forma que
mientras más complicado
mejor, porque entonces
las personas las podemos
hacer pasar por una
certificación o por una
capacitación que vamos a
cobrar.
Entonces, es la misma
ideología de muchos
sistemas que tienen
tráfico, que son
populares, que añaden
una capa de complejidad
encima adrede, ¿no?
Porque es adrede.
¿Es adrede para qué?
Para que tú tengas que
capacitarte, para que
sea más difícil escapar.
Una vez que invertiste
tiempo en aprender un
sistema, ya estás ahí
dentro y ya no quieres
reaprender ningún otro y
sientes que has
invertido mucho tiempo
como para cambiarte.
Todo eso es psicológico
y el mercado domina
perfectamente.
El capitalismo funciona
a partir de
manipulación.
Entonces, una vez que
uno invierte en un
sistema complejo, ya no
se va, ¿sí?
Entonces, ese tipo de
sistemas están ahí para
eso.
Entonces, Formmy te deja
usar WhatsApp Business
sin costo.
