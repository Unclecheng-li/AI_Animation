# 生产纪律（cue 对齐 · 数字白名单 · QA 流程 · 母版骨架）

## cue 对齐（口播即时间轴）

- **cue 时刻 = 口播句起点(绝对时间) − 镜头起点(绝对时间)**；每行 cue 注释写口播原句+时间戳：`on(13000,()=>{...}); // 1:50「比如说你在网上看到一个AI开源项目」`；
- DUR = 分镜时长精确到毫秒；**口播不上屏**（页面只放关键词/标题/数据，字幕条禁用；仅分镜明确要求逐字上屏的例外）；
- 补间对象必须 `e`+`f` 双字段（历史坑：缺 e 报 undefined）；`after(ms,f)` 做相对排程。

## 数字白名单纪律

页面出现的每个数字必须来自素材（口播稿/分镜表），**不许编**；同一数据全系列一致（3300 star 每页都是 3300）。无出处的模糊量用"50+/约两分钟"式写法。有数据的页角注出处（`#src`）。

## 红线

- 不伪造终端回显/DVWA/XAMPP 等真实界面输出（抽象"黑窗口图形"可以，但不写真实命令输出）；B 类拟真页不露宿主机真实信息（路径/用户名用中性示例）；
- 授权红线表述沿用素材原句（如"只能打授权目标"），不自行改写弱化。

## QA 流程（每页必做，底盘自带钩子）

1. **截图**（≥4 时间点：开场/中段/高潮/结尾）——URL 加 `#auto,t=毫秒`，起播后自动冻结在该时刻：

```powershell
$edge="C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
& $edge --headless --disable-gpu --hide-scrollbars --window-size=1920,1080 --virtual-time-budget=4500 --screenshot="_qa\p_t6000.png" "file:///C:/路径/shot-x-x.html#auto,t=6000"
```

（用 Shark-GIF 相对路径时把页面复制到临时 ASCII 目录连同 GIF 一起，或先 cp 素材进输出目录。）

2. **控制台零错误**：`--dump-dom` + stderr 日志，`Select-String "Uncaught|SyntaxError|TypeError|ReferenceError"` 应为空。
3. **审美四问**：① 纸底/墨字/发丝线系统一致？② 无残留发光/渐变/油光？③ 大字层级与网格成立、主视觉 ≥55%？④ 图表词汇真实落位且与内容匹配？
4. 逐张读截图查：重叠遮挡/中间态穿帮/收尾定格/孤儿元素。

## 已知坑

- `marker-end` 箭头在 dash 隐藏路径上会提前渲染 → 箭头用独立 polygon；
- 上一幕元素与下一幕同位置 → 必须 cue 淡出，否则穿帮；
- Google Fonts 未加载完成时无头截图缺字体 → virtual-time-budget ≥4500 等 fonts.ready。

## 母版骨架（多镜复用必须一致——同骨架页共享组件与节奏）

| 骨架 | 用途 | 要点 |
|---|---|---|
| 开场 hero | 系列/产品开场 | 0-2s 内强视觉：eyebrow+巨字+大字计数；五幕结构=计数→对比→指令→循环环→报告（shot-0-1 范本） |
| 时间线 | 事故/演进 | 四步卡横向推进，状态逐级恶化=灰阶变深，焦点=橙 |
| 数字对撞 | 倍数冲击 | 两个巨数对撞+×N 计数+小对照图 |
| 数据大字 | 清单砸落 | 大数字逐条砸落成堆+出处角注 |
| 嵌套示意 | 概念地基 | 大框套小框+粗隔离边界+内框清单，做精 |
| 双列对照 | 二分概念 | 硬分割两栏+底部一句结论 |
| 结论收束 | 铁律/金句 | 居中大字+支撑条目+极简留白，节奏放慢 |
| 循环卡 | 习惯/流程 | 闭环四站+中心句 |
| 计票清单 | 对账/清单 | 逐条打勾+计数 |
| 片尾卡 | 资料/三连 | 清单收敛+领取方式+再见 |

## 翻新已有页面时

1. 先盘点：哪些页残留暗色油光/文字堆砌（无图表）——列清单给用户，点名保留的一字不动；
2. 逐页"读一页→重画一页→QA 一页"：底盘 cue 时刻与注释**逐条保留**（对齐口播不动），只换视觉层；
3. B 类仿真页只换外围框架（舞台/页头/标注/角注/结论条），仿真本体不动；
4. 旧"实体锁色/字体轮换"体系一律废止，统一瑞士 tokens。

## 大肥鱼使用法

每页 1-2 次（中段快闪或结尾定场），放留白区；纸底气泡（白底+1px 墨边+黑字+橙 `<b>`）；配 pop(.5)。高频款：乖巧期待/愤怒抓狂/委屈求助/痛哭/请求拜托。不用安安雪莉。
