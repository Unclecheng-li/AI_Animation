03

人类基本不犯的低级错误

这些安全陷阱在 AI 生成代码中却频繁出现

幻觉包
引用不存在或来源不明的依赖，埋下供应链隐患
  • 依赖名拼写错误 / 使用占位符仓库
  • 版本号或包路径根本不存在
  • 引入私有或已下架的第三方库
漏掉授权
接口缺少身份校验与权限控制，任意用户可操作
  • API 端点未验证 JWT / Session
  • 普通用户可直接访问管理员接口
  • 对象级权限检查缺失
配置即执行
把外部配置直接拼接进命令执行，造成 RCE 风险
  • 用户输入直接拼进 shell 命令
  • eval / exec 执行动态配置字符串
  • 环境变量未过滤注入恶意参数
人类开发者通常能凭经验避开这些陷阱
