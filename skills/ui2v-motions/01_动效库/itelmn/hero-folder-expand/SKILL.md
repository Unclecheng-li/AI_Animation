# Hero Folder Expand

A yellow project folder flaps open and a paper sheet rises listing composition files. Function: **project contents reveal**.

## Purpose

- File, workspace, and packaging heroes
- Physical folder flap (rotateX)
- Warm sticky-note palette

## Specs

- Front flap hinges from the bottom edge
- Paper eases upward after the flap clears
- Entry: `index.html`

## Usage

```bash
npx hyperframes preview
ui2v motion publish . --version 1.0.0
```

## Notes

Keep the file list to three lines. Longer manifests overflow the paper card.
