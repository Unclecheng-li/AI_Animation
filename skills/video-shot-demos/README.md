# video-shot-demos

> 电影级视频分镜演示动画 Skill —— 一个镜头一个 HTML，两辑 40 种风格轮换

## 简介

把一个视频项目的分镜做成一辑**可以直接全屏录屏当成片用**的网页演示动画：一个镜头 = 一个独立 HTML。整辑共享同一套电影化播放器底盘（黑场起手、虚拟时钟、HUD、可暂停重播），但**每个镜头用完全不同的视觉风格**创作——复古报纸、便利店 POS、审讯室软木板、像素平台游戏、武功秘籍、机场安检，或黑色电影档案、黄铜天平、集换式卡牌卡册、地铁线路图……把抽象内容具象成一个"世界观"。

内容完全开放：技术实测、产品发布、课程讲解、故事叙述都能套用（内置两套完整实例分别服务安全实测与论文阅读两个领域）。核心是统一的电影化机制 + 镜头语言 + 完成度标准。

## 核心机制（全部页面统一的"底盘"）

| 机制 | 说明 |
|------|------|
| **黑场起手** | 劫持 `performance.now()` 成虚拟时钟——点击「启动播放」前时间恒为 0，点击后黑场渐变 2s 再开演。CSS 动画与 JS cue 共用一时钟永不漂移，录屏干净起手 |
| **HUD 隐藏唤出** | 进度条/时间码默认隐藏，鼠标移到画面底部 60px 唤出（录屏画面纯净） |
| **镜头语言** | 全画面包进 `#cam` 层做推拉摇移：开场拉镜、关键时刻推近、转场拉回、跟拍、Ken Burns 缓推、冲击快推；慢放段落配黑边 + 暗角 + 毫秒计数器 |
| **WebAudio 合成音效** | 零音频文件，6 个原语（pop/whoosh/swipe/type/ding/thud）；镜头运动自动挂 whoosh，数字滚动配缓出连击键音 |
| **角色表情特写** | 安安 15 张情绪立绘按节拍选图，400px 级特写 + 吐槽气泡，淡入登场 |
| **字幕条同步** | 与口播稿逐句对齐，关键词高亮；cue 注释引用口播时间戳 |
| **无头截图质检** | 虚拟时钟可快进到任意毫秒截图，逐张检查重叠遮挡/完成度/动画穿帮 |

## 创作哲学

1. **风格是轮换的，不是品牌** — 连续两个镜头绝不同风格；每种风格对应它最擅长的内容类型
2. **禁用默认科技暗色** — 黑底 + 霓虹发光的"乌漆墨黑油光锃亮"风是最大败笔
3. **想象力 > 规范** — 意想不到的隐喻、实体的机械结构、会砸下来的印章、会掉进存钱罐的硬币
4. **完成度是纪律** — 每个元素有入场动画、无重叠遮挡、结尾有重播暗示、数据有出处角注

## 使用方式

```
这是我视频的口播稿和分镜（贴文），用 video-shot-demos 给每个镜头做一个演示动画 HTML，输出到 demo/
```

```
把这批演示页翻新一下，好几页都是黑底发光风格，太土了，每页换不同风格
```

```
给所有演示页补上镜头推进和音效，再整体质检一遍有没有遮挡问题
```

## 核心特性

- **电影化播放器** — 黑场启动 / 虚拟时钟 / 暂停重播 / 悬停唤出进度条
- **镜头调度系统** — camTo/camFocus 推拉摇移 + 黑边慢放 RACE CAM
- **WebAudio 音效引擎** — 6 原语合成，音画逐帧同步
- **40 种视觉风格库（两辑实例）** — 每种配字体组合 + 适用内容 + 成片样板
- **角色情绪速查表** — 15 张立绘 → 15 种叙事节拍的映射
- **吐槽气泡统一模板** — 形态逐字锁定（圆角/字号/箭头/入场曲线跨项目一致），只开放 4 个配色参数与朝向镜像
- **质检工作流** — 无头截图多时间点验证重叠/遮挡/完成度

## 技术栈

- 原生 HTML/CSS/JS（零构建、零依赖，单文件即开即用）
- WebAudio API（音效合成）
- Google Fonts（每页 2–4 族，与风格严格配对）
- Node.js + Chrome/Edge headless（可选，仅质检脚本用）
