QClaw 架构原理

本地 Gateway + 云端模型 + 插件扩展

核心特性

  • • 本地运行: 数据不出本机, 隐私安全
  • • 微信直联: 微信是遥控器, 电脑是工人
  • • 多 Agent: 3 个 Agent 并行协同工作
  • • 技能生态: 5000+ Skill 插件扩展

技术栈

  • • 底层框架: OpenClaw 开源项目
  • • 通信协议: MCP (Model Context Protocol)
  • • 会话管理: 持久记忆 + 上下文状态
  • • 安全模型: 沙箱隔离 + 权限控制
