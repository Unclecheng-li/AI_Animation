# Hero Soft Mesh

Overlapping pastel radial fields form a soft mesh on a warm paper ground. Function: ambient brand atmosphere, opposite of hard UI chrome.

## Purpose
- Lifestyle and creative brand opens
- Light backgrounds in a mostly-dark catalog
- Slow drift instead of punchy hits

## Specs
- Mesh scales and drifts under multiply type
- Serif title for editorial softness

## Usage
Publish after lint. Preview full frame to judge blur bloom.

## Notes
If blur is unsupported, the layered radials still carry the mesh idea.
