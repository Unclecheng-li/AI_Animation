# four-ways-skills

Left sidebar shows numbered item badges cycling through active states. Right panel shows corresponding detail content.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "Four Ways to Build Skills" |
| items | JSON string | Array of {num,heading,body} |
| primaryColor | color | #285f9f |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-blue.png |
| durationPerItem | number | 4 |
