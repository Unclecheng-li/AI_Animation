deepseek-tui

Rust TUI ⚠️ 投毒演示 🎣 蹭热度

一个基于 Rust 的 DeepSeek 终端交互工具。支持流式对话、代码高亮、会话历史、多模型切换。使用 ratatui 构建现代化终端界面，性能优异，内存占用低。

🌟 347 Stars · 曾登上 GitHub Trending (Rust) · 18 Forks

⚠
体积异常：比正常 Rust TUI 项目多出 2.1MB

这 2.1MB 藏在 assets/bin 目录下，声称是"预编译资源"，实际是加密的后门木马载荷。build.rs 在编译时将其释放到系统目录。

安装

bash
1cargo install deepseek-tui
2# 或从源码构建
3git clone https://github.com/deepseek-tui/deepseek-tui.git
4cd deepseek-tui && cargo build --release

功能特性

• 流式对话 — 实时显示 DeepSeek API 响应，打字机效果
• 代码高亮 — 内置 50+ 语言语法高亮
• 会话管理 — 本地 SQLite 存储历史记录
• 快捷键支持 — Vim 风格键位，可自定义配置
• 多模型切换 — 支持 DeepSeek-V2、DeepSeek-Coder

攻击者利用了什么

这种攻击的核心不是技术复杂，而是"蹭热度 + 伪装正常"。仓库名、README、Star 数、Trending 标签、MIT License 都在服务同一个目的：让你相信这是一个值得尝试的开源工具。

常见套路

• 蹭热点名称：deepseek、tui、rust 都是高搜索量关键词
• 刷 Star / 上 Trending：快速积累虚假人气，制造"社区认可"假象
• 功能看起来正常：核心代码确实能跑，隐藏载荷在编译/运行时释放
• 体积增量隐蔽：2.1MB 在 Rust 二进制中不显眼，容易被忽略
• build.rs 投毒：Rust 构建脚本在编译阶段执行，绕过运行时检测

✓ 正常 Rust TUI 项目

  • 源码体积与功能匹配
  • build.rs 简单或不存在
  • 无异常二进制资源文件
  • 作者有持续贡献历史

✗ 投毒仓库特征

  • 体积异常增大（+2MB+）
  • build.rs 包含复杂逻辑
  • assets/bin 等可疑目录
  • Star 数与贡献历史不匹配
