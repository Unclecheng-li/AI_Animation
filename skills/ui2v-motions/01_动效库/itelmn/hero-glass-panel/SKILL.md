# Hero Glass Panel

A frosted glass workspace card floats over a cool radial field with three metric pills. This is a product-UI hero, not kinetic type or particle work.

## Purpose
- SaaS dashboard storytelling
- Soft UI affordances without real screenshots
- Center-stage card entrance

## Specs
- Centered glass panel, 4.5 seconds
- Badge, title, and metric row stagger

## Usage
npx ui2v@latest install hero-glass-panel then preview.

## Notes
Backdrop-filter may flatten in some render paths; the translucent fill still reads as glass.
