# faqs

Left sidebar lists questions cycling through active states. Right panel shows the corresponding answer.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "Frequently Asked Questions" |
| faqs | JSON string | Array of {question,answer} |
| primaryColor | color | #285f9f |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-blue.png |
| durPerItem | number | 5 |
