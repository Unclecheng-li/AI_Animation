# Hero Pixel Rain

Columns of square pixels fall on the right half of the frame while the title holds the left. It is a matrix-inspired atmosphere piece without noisy particles.

## Purpose

- Developer and AI product heroes
- Teaching multi-track column animation
- Registry content with strong silhouette

## Specs

- Ten columns, deterministic fall distances
- 1920x1080, 4.5 seconds

## Usage

npx ui2v@latest install hero-pixel-rain then preview.

## Notes

Columns stay on the right so type never collides with the rain field.
