# curved-timeline

Horizontal timeline with milestone dots. Each milestone highlights in turn, cycling detail panels on the right.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "Project Implementation Roadmap" |
| milestones | JSON string | Array of {year,label,heading,body} |
| primaryColor | color | #285f9f |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-blue.png |
| durPerItem | number | 4 |
