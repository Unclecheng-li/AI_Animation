二、临时缓解措施

未修复服务器的临时防护方案
  • 禁用 HTTP/2：暂时回退到 HTTP/1.1，彻底杜绝攻击面
  • 部署代理：在前端部署严格限制头部数量的反向代理
  • 容器限制：通过 cgroups 限制 Worker 进程内存，确保被攻击时能及时杀死并重启
紧急建议
对于使用 Microsoft IIS、Envoy、Cloudflare Pingora 的用户， 建议立即采取临时缓解措施。在官方补丁发布前， 禁用 HTTP/2 或部署限制代理是最有效的防护手段。
