# Hero Stamp Seal

A release certificate sits on white paper stock until a heavy red rubber stamp strikes APPROVED. Function: **authorization / clearance** — bureaucratic object motion.

## Purpose

- Compliance, release, and QA storytelling
- Physical stamp impact (scale-in + settle)
- Paper document aesthetic

## Specs

- Stamp enters oversized, then impacts and settles
- Slight residual rotation so it feels hand-placed
- Entry: `index.html`

## Usage

```bash
npx hyperframes preview
ui2v motion publish . --version 1.0.0
```

## Notes

Keep stamp text short. Multi-line seals lose force at thumbnail size.
