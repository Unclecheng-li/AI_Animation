# 草崩し Chrome 拡張 — 画面録画（E1 + E2）

Web 版の確定版 C（`../kusakuzushi-site/compositions/s10-screen.html`）と同じ文法の画面録画。
テロップなし・無音。コンポジションは `compositions/e1-screen.html`（スタンドアロン、1080×1080、60fps、17.1s）。
書き出しは `npm run render -- -c compositions/e1-screen.html -q delivery -o renders/e1-screen.mp4`。

## 素材（`assets/ext/`、すべて実測）

- 画面（3840×2160、1920×1080 CSS の 2 倍撮り、ダーク、ログインなし、scrollY 0）:
  `mounted.png`（「🎮 崩す」あり）/ `button-hover.png`（同ボタンにホバー）/ `ready.png`（ゲーム開始直後：カードが下へ 100px 伸び、
  盤面・「クリック / Space で発射」・Score/Life、ボタンは「やめる」）/ `result.png` / `result-quit-hover.png`（結果表示の「やめる」にホバー）/
  `restored.png`（やめた後：草が全部緑、カードは元の高さ、ボタンは「🎮 崩す」）。
- 盤面の映像（1494×522 = CSS 747×261、カードの枠線ちょうど）: 拡張の実コードを本物のページで動かして撮ったもの（シード 38、
  エンジン初期値＋拡張の盤面寸法、球は最大 200、一度も落とさず 24.7s で全消し）。
  - `e-hook.mp4`（3.0s、等速、元 17.2–20.2s の最も球が多い区間）
  - `e-early.mp4`（3.9s）= 最初の 1 コマを 0.15s 止め → 元 0–0.5s を等速（0.5s で発射）→ 元 0.5–7.0s を 2 倍速
  - `e-end.mp4`（3.75s）= 元 21.2–24.7s を 1.5 倍速（2.333s）→ 全消しの瞬間から等速 0.5s（結果表示が出る）→ 最後のコマで 0.9s 静止
- `cursor-path.json`: プレイ中の十字カーソルのページ座標（60fps の出力フレームごと。`x = 盤面左端 714.83 + 記録したパドル中心`、`y = 841`）。
  `hook`（180 個）/ `early`（234 個）/ `end`（225 個）。
- 座標（CSS px）: 盤面 canvas x 714.83 / y 676 / 692×194。カード（枠線あり、角丸 6px）x 672 / y 644 / 746.66×261（開始後。開始前と
  やめた後は高さ 161）。「🎮 崩す」ボタン x 672 / y 805 / 66.45×28（開始前）。結果表示の「やめる」ボタン x 1031.81 / y 839.5 / 62×28。

## Video direction

- **カメラは動かさない**。`#camera`（1920×1080、transform-origin 0 0）を `x −923.46 / y −432 / scale 1.4`（中心 (1045.33, 694.29)）で固定。
  下端をスクショの下端（CSS y 1080）ちょうどに合わせている。当初の中心 y 772.5 では撮影範囲の外が 78px 映り、GitHub の地 `#0d1117` と
  動画の地 `#0C110D` の色違いの帯が下端に出たため上へずらした。
  この構図は左列のプロフィール情報（右端 ≈ x 648）と右の年リスト（x ≈ 1450〜）、ページ上部のログイン前ヘッダーを画面の外に出す。
  草が画面いっぱいに入っているので、C の原則（動くのはクリックが理由のときだけ）に照らして動かす理由がない。
- 盤面の映像は `#camera` の中、カードの矩形（x 672 / y 644 / 747×261）に置いた `overflow:hidden; border-radius:6px` の枠で表示する。
  映像の端はカードの枠線に重なるので継ぎ目は出ない。ただし映像とスクショはカード内の地の色が 2 段階違うので、
  **同じ中身のまま映像⇄スクショを切り替えない**（切り替えは中身が変わる瞬間だけ。止めたい場面は映像のコマ止めを使う）。
- カーソル（`#camera` の中、ページ座標、約 16px＝画面上 22px、白地に黒 1.5px の縁、影なし）:
  矢印・指（GitHub の `.btn` は pointer）・十字（盤面 canvas は `cursor: crosshair`）。クリックはカーソルの `scale 0.85→1`（0.12s）。
- テロップなし。エンドカードは C と同じ体裁。
