# Stacked Data Cards — Prompt 参考

## 1. 基础生成

```
用 stacked-data-cards 把以下论点做成叠放数据卡动画：
1. {论点一} — {支撑数据}
2. {论点二} — {支撑数据}
3. {论点三} — {支撑数据}
整段 {N} 秒，{主题色} 主题
```

```
用 stacked-data-cards 展示 {研究/报告} 的核心结论，{N} 张卡片，每张驻留 {N} 秒
```

## 2. 时间线与退场

```
整段对应口播 0:25-0:50，共 25 秒，3 张卡按 7s / 7.5s / 10.5s 分配
```

```
结尾整副牌堆向左滑出退场，衔接下一镜头
```

```
以 assets/template.html 为骨架，做 {N} 张论点卡，时间线常量集中在 TIMING
```

## 3. 组件指定

```
第 1 张卡用折线对比图：{A 指标} 上升、{B 指标} 持平，底部加金句「...」
```

```
第 2 张卡用大数字 + 环形仪表展示 {45%}，配 {AI vs 人类} 对比条和数据表格
```

```
第 3 张卡用 3 栏图标卡组展示 {要点A / 要点B / 要点C}，底部金句横幅收尾
```

```
每张卡右下角加角注，标注数据来源 {来源 · 样本量}
```

## 4. 风格调整

```
用 stacked-data-cards 做 {主题}，要求：
- 主题色 {橙红 #ff5f3c / 蓝 #3b82f6 / 绿 #10b981 / 紫 #8b5cf6}
- 卡片宽度 {900~980}px
- 舞台光晕 {加强/关闭}
- 关键揭示时刻加低音 thud 音效
```
