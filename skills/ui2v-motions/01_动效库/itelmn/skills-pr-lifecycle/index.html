How a change reaches main.
01
Work on stage — the default branch, and unprotected
git switch stage
02
Add the skill, then run it end to end against a real target
skills/<name>/SKILL.md
03
Sync the plugin manifest, then validate
npm run sync && npm run validate
04
Push, then open a pull request into main
base: main · compare: stage
05
The required check runs on the pull request
skills + manifests
06
An admin reviews it, then accepts it or closes it
quality · value · fit
