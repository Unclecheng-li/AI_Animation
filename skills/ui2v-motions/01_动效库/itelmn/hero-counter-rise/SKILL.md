# Hero Counter Rise

A large metric counts from zero to one hundred twenty-eight while a supporting chip slides in. Use it for growth and traction storytelling on UI2V.

## Purpose

- Stats and traction heroes
- Demonstrating deterministic onUpdate counters
- Pairing big numbers with secondary context

## Specs

- Counter object animated by GSAP, no Date.now
- Duration 4.5s at full HD

## Usage

ui2v install hero-counter-rise, preview the count, then pin on the homepage if desired.

## Notes

If you change the end value, also update the supporting chip copy so the story stays coherent.
