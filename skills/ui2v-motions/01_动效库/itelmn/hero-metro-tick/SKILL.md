# Hero Metro Tick

A metro track draws across the frame, station ticks appear, and an orange train marker travels from Init to Ship. It is a timing metaphor for shipping workflows.

## Purpose

- Devtools and pipeline storytelling
- Precise reveal choreography with many tracks
- Homepage heroes that feel scheduled, not floaty

## Specs

- 1920x1080 @ 30fps, 4.5 seconds
- Separate tracks for ticks, stations, and the train

## Usage

ui2v install hero-metro-tick, then scrub the train path in HyperFrames preview.

## Notes

Keep station labels short. Longer copy breaks the transit diagram clarity.
