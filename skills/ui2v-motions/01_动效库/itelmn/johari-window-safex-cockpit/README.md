# johari-window

2×2 grid of the four Johari Window quadrants. Each quadrant highlights in sequence with its detail panel.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "The Johari Window" |
| quadrants | JSON string | Array of exactly 4 {label,heading,color,body} |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-blue.png |
| durPerItem | number | 5 |

Each quadrant carries its own `color` (supports per-quadrant ACS plate colours).
