# tuckman-model

Animated chart with stage dots that highlight as content cycles through Tuckman's four team development stages.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "Tuckman's Model..." |
| stages | JSON string | Array of {name,heading,body} |
| dotColor | color | #285f9f |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-blue.png |
| duration | number | 16 (total, divided by stage count) |
