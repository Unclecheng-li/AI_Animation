# 音效系统（WebAudio 合成 · 零音频文件）

全部音效用 WebAudio 现场合成——不依赖任何音频资产，单文件 HTML 拷走就能响。引擎代码在 `assets/template.html` 第二节，逐页原样复制。

## 六个原语（语义优先，按"发生了什么"选）

| API | 拟声 | 语义场景 | 常用音量 |
|---|---|---|---|
| `pop(vol)` | 波 | 元素弹出、气泡出现、小揭晓 | 0.5–0.8 |
| `whoosh(dur,vol)` | 呼 | **镜头运动**、大幅位移、慢放出入场 | 0.35–0.9 |
| `swipe(vol)` | 唰 | 快速滑入、切换、页面入题 | 0.4–0.8 |
| `type(vol)` | 键 | 单次打字、单步计数 | 0.3–0.7 |
| `ding(vol)` | 叮 | 落定、成功、结论出现 | 0.6–1.0 |
| `thud(vol)` | 咚 | 撞击、盖章、重物落下、报错砸场 | 0.7–1.2 |

## 自动解锁

浏览器自动播放策略要求 AudioContext 在用户手势后才能出声。引擎挂在 `pointerdown` 上 `ensure()+resume()`——用户点「启动播放」按钮那一刻就已解锁，开演必有声。注意引导脚本里按钮点击不要 `stopPropagation`。

## Cue 记法与批量模式

音效 cue 与叙事 cue 写在同一个时间轴里，集中在主脚本尾部一个 `/* ===== 音效 ===== */` 块：

```js
on(300,()=>__sfx.swipe(0.6));                    // 入题
on(10800,()=>__sfx.thud(1));                     // 盖章机砸下
on(30500,()=>__sfx.thud(1.1));                   // 入账①
for(let i=0;i<12;i++)on(40300+i*135,()=>__sfx.type(0.4));   // Tn：等距连击
```

两种连击（对齐数字滚动时用）：

- **Tn（等距连击）**：`for(i<n) on(t+i*gap, type)` —— 打字机、逐条弹列表。
- **TnE（缓出连击）**：`i/(n-1)` 做 `1-(1-u)^(1/3)` 映射，先密后疏，最后一下正好落在计数结束——`cnt()` 数字滚动的减速感被声音复现，非常舒服。

镜头音效已内置：`camTo` 每次自动带 `whoosh(dur,0.65)`，不用重复配。

## 配乐原则

1. **每个关键动作都要有声音**：出现=pop/swipe，落定=ding，砸下=thud，镜头=whoosh。静音的动画像坏了。
2. **同样克制**：一秒内不超过 2-3 个音；叙述性停顿（口播换气、字幕切换）留 0.5s 以上静默。满屏乱响 = 廉价。
3. **音量即层级**：主揭晓 0.9–1.2，日常元素 0.4–0.6，背景性连击 0.28–0.4。
4. **与动作同帧触发**：音效 cue 的时间戳必须和视觉 cue 相同或 ±50ms，不同步比没有更糟。
5. 主总线 master gain 0.24、lowpass 6500Hz 已调好——所有声音自带"隔了一层"的舒服质感，不要改。
