# 仿真叙事手法（怎么用真界面讲故事）

## 光标演出（本体系的"主角"）

- 光标全程可见（`#cur.show` 后不再隐藏），每一步操作都有物理轨迹：`curTo(x,y,dur,arc)` 弧线飞行 → hover（可选微缩）→ `clickFx()` 点击缩放反馈；
- **双击 = 两次 clickFx 间隔 300ms**，随后触发视图切换——观众从光标节奏里读出"我在双击"；
- 光标先行、界面后动：`curTo` 到位 300ms 后再 click，click 后 200ms 再触发界面响应；
- 多步教学（如"回收站三步"）每步 = 移动 → 点击 → 界面反馈 → camFocus 轻推，形成节拍感。

## 视图切换三同步（还原真实导航）

进入下一级目录时**必须**同时更新三处，缺一处就穿帮：

```js
$('#viewPC').classList.add('hide');$('#viewC').classList.remove('hide');  // 视图交叉淡切
$('#wtabTxt').textContent='本地磁盘 (C:)';                                 // 标签页
$('#addrTxt').innerHTML='此电脑 <span class="crumb">›</span> 本地磁盘 (C:)';// 面包屑
$('#statL').textContent='6 个项目';                                        // 状态栏
```

新视图文件列表 stagger 95ms 逐个入格（配 type 轻击音）。

## 真实系统文案库（细节可信度来源）

- 错误对话框标题格式：`程序名.exe - 应用程序错误`，正文带真实错误码（0xc0000142 等）；
- 通知原文："本地磁盘 (C:) 的空间不足。请释放一些空间，否则某些应用可能无法正常运行。"
- WinRE 阶段文案："正在准备自动修复" → "自动修复" → "无法修复你的电脑"；蓝屏百分比 0%→100% 用 cnt；
- 面包屑分隔符 `›`；状态栏"N 个项目"；磁盘"可用空间不足/充足"。

## 因果链叙事（系统演示的剧情引擎）

**操作 → 后果 → 教训** 三段式是 sim 页最常用的弧线：
乱删文件夹（poof 动画 + 状态栏项目数减少）→ 容量几乎没变（93%→92.2%）→ 第二天程序报错（dlg1）→ 系统文件缺失（dlg2）→ 蓝屏自动修复（reScreen）。每段配光标操作与镜头推近， dread 逐步升级。

## 教学讲解位置

- 口播讲到"哪个能删？"→ 问号徽章逐一 pop 到可疑文件夹上；
- 讲到结论 → 红圈圈住目标 / 警告徽章弹出 / 容量条爆红呼吸；
- 数据对比 → 占比浮层（环形/色块）搭在资源管理器上方，讲完即撤。

## 角色 GIF 吐槽（大肥鱼式）

- 位置：右侧 `.fish` 290px，GIF 自带动效只需入场弹簧 + drop-shadow；
- 时机：情绪锚点（报错瞬间=震惊呆滞款、乱删时=腹黑威胁款、翻车后=摆烂款）；每页 1–2 次，3–6s 后退场；
- 选图按文件名情绪词直选（`043_眼睛圆圈失神嘴巴抿着震惊呆滞.gif`）；无 GIF 素材时换任意立绘/纯 CSS 吉祥物，同位置同节奏；
- 立绘角色（如安安）客串沿用 video-shot-demos 的气泡强约束模板。

## 与实拍录屏的混剪约定

整辑视频里 sim 页负责"系统内视角"，实拍负责真人/软件界面——index 总览用类型标注区分，shot 编号全局对位，剪辑时按编号拼接。sim 页角注必须保留 **"界面为演示还原 · Windows 11 版式"**（规避商标/混淆问题的声明）。

## cue 注释规范

时间戳对齐口播：`on(3000,()=>{...});  // (0:03) 系统提示空间不足`——录屏剪辑时按注释核对口播位置。
