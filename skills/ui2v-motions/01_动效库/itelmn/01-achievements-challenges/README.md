# achievements-challenges

Cycling two-column layout. Each cycle reveals a paired achievement (left, green) and challenge (right, red). Progress dots indicate current position.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "Project Retrospective" |
| leftLabel | string | "Achievements" |
| rightLabel | string | "Challenges" |
| items | JSON string | Array of {left,right} pairs |
| leftColor | color | #2f765f |
| rightColor | color | #cd5746 |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-green.png |
| durationPerItem | number | 4 |
