# Hero Upload Drop

A mint drop zone catches a zip card and fills a progress bar to ready. Function: **import / upload / asset intake**.

## Purpose

- Media upload, package import, and drag-drop heroes
- File card drop + percent bar
- Fresh emerald field

## Specs

- File card lands then the zone solidifies
- Fill and percent share a 1.8s ease
- Entry: `index.html`

## Usage

```bash
npx hyperframes preview
ui2v motion publish . --version 1.0.0
```

## Notes

Keep the dashed border until the drop settles — that visual change sells the hit.
