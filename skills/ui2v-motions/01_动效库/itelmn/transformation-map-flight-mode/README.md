# transformation-map

Road SVG with milestone markers. Active milestone highlights in accent colour with a detail panel.

## Variables

| Variable | Type | Default |
|---|---|---|
| title | string | "Digital Transformation Roadmap" |
| milestones | JSON string | Array of {year,label,heading,body} |
| primaryColor | color | #285f9f |
| accentColor | color | #cd5746 (active highlight) |
| bgColor | color | #f5f2ea |
| basePlateImage | string | v2-base-blue.png |
| durPerItem | number | 4 |
