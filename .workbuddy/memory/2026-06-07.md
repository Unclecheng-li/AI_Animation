## 创建学霸笔记 Skill

参考 guizang-ppt-skill (https://github.com/op7418/guizang-ppt-skill) 的项目结构，基于 C:\Users\UncleC\Desktop\Note 下的 5 个笔记模板，创建了「学霸笔记」Skill。

### Skill 位置
`~/.workbuddy/skills/note-skill/`

### 文件结构
```
note-skill/
├── SKILL.md                    # 主规范文档
├── assets/
│   └── template.html           # 基础模板（手写笔记本风格）
└── references/
    ├── layouts.md              # 18 种页面布局
    ├── components.md           # 组件手册（文字样式、标签、涂鸦等）
    └── checklist.md            # 质量检查清单（P0-P3）
```

### 设计特点
- 手写笔记本视觉：Kalam/Patrick Hand/Zeyada 字体 + 米黄横线纸 + 螺旋装订孔
- 装饰元素：胶带、回形针、咖啡渍、涂鸦 emoji
- 18 种布局组件：流程图、对比框、攻击链、代码块、警告框、便签等
- write-in 入场动画：模拟"边写边出现"效果
- 响应式设计：移动端便签变为相对定位

### 模板来源
分析了 5 个笔记模板（Note1-Note5），提取了通用 CSS 变量、组件类名、布局结构。
